     - For any character or scene with revisions, synthesize historical version nodes:
       - `node-char-{id}-v1` $\to$ `edge(relation_type="refined_from", label="Creator Refinement")` $\to$ `node-char-{id}-v2`.
       - Explanations state user revision notes without exposing CoT tokens.
  2. Create `backend/app/services/persistence_service.py`:
     - `PersistenceService(repo: ProjectRepository, storage: StorageProvider, lineage_service: LineageService)`:
       - `branch_project(source_project_id: str, request: BranchCreate) -> Project`:
         - Retrieves source project.
         - Creates child Project with `parent_project_id = source_project_id`, `branch_name = request.branch_name`, and title `${source.title} (${request.branch_name})`.
         - **Strict ID Remapping**:
           - Builds `candidate_id_map: Dict[str, str]` mapping parent candidate IDs to new child candidate IDs.
           - Clones world candidates with new IDs under child project.
           - Clones world selection, remapping `world_candidate_id = candidate_id_map[parent_sel.world_candidate_id]`.
           - Clones world bible, remapping `world_candidate_id = candidate_id_map[parent_bible.world_candidate_id]`.
           - Builds `char_id_map: Dict[str, str]` mapping parent character IDs to new child character IDs.
           - Clones characters with new IDs and remapped `world_candidate_id`.
           - Clones relationships, remapping `source_character_id = char_id_map[...]` and `target_character_id = char_id_map[...]`.
           - Clones scenes with remapped `world_candidate_id`.
           - Returns created child Project.
       - `refine_character(project_id: str, char_id: str, req: CharacterRefineRequest) -> CharacterRead`:
         - Snapshots current state in `entity_revisions` before update.
         - Updates character fields, increments version, sets revision notes.
         - Snapshots new state in `entity_revisions`.
       - `refine_scene(project_id: str, scene_id: str, req: SceneRefineRequest) -> SceneRead`:
         - Snapshots current state in `entity_revisions` before update.
         - Updates scene fields, increments version, sets revision notes.
         - Snapshots new state in `entity_revisions`.
       - `export_project_bundle(project_id: str) -> ProjectBundle`:
         - Bundles all relational data for project PLUS calls `await self.lineage_service.build_project_lineage(project_id)` to populate `lineage`.
       - `import_project_bundle(bundle: ProjectBundle) -> Project`:
         - Unpacks bundle entities with fresh or restored IDs and inserts into database.
       - `create_storage_snapshot(project_id: str) -> SnapshotRead`:
         - Exports project bundle with lineage as JSON bytes.
         - Calls `await self.storage.upload(file_data=bundle_bytes, key=f"snapshots/{project_id}/snapshot_{timestamp}.json", mime_type="application/json")` using the verified `StorageProvider.upload` method.
         - Records Asset in repository and returns `SnapshotRead`.
       - `list_storage_snapshots(project_id: str) -> List[SnapshotRead]`.
       - `get_project_revisions(project_id: str) -> List[EntityRevisionRead]`.
