# Phase 49: Azure Scale-to-Zero Worker Pilot & Cloud Benchmarking Plan

## Phase Goal
Deploy and verify an isolated native cinematic rendering worker in Azure Container Apps (`praroha-cinematic-worker`) configured for scale-to-zero serverless operation (minReplicas=0, maxReplicas=1) on 1.0 vCPU / 2.0 GiB RAM. Execute bounded cloud rendering benchmarks against authentic world assets, empirically measure render latency, memory RSS, and Azure billing against the ₹500 budget, and verify failure handling, security validation, and full Supabase Storage / PostgreSQL persistence round-trips.

---

## Architecture Contract & Reconciled Design

> [!NOTE]
> **Architecture Decision Record**: Azure Container Apps Jobs were unsupported in the existing ACA managed environment (`env-tendersaathi`, Consumption/Express tier). The worker was therefore architected and deployed as an internal-only scale-to-zero Azure Container App (`praroha-cinematic-worker`). When idle, the replica count drops to 0 (`minReplicas: 0`), incurring ₹0.00 idle cost while preserving full process isolation from the primary API container.

```mermaid
graph TD
    Client[Primary API: praroha-backend] -->|HTTP POST /render + Bearer Token| WorkerApp[ACA Worker: praroha-cinematic-worker]
    WorkerApp -->|Scale 0 -> 1 on Demand (1.0 vCPU, 2.0 GiB)| IsolatedInstance[Worker Container Replica]
    IsolatedInstance -->|Fetch Source Keyframe Asset| SupaStorage[(Supabase Storage: seed-unfold-assets)]
    IsolatedInstance -->|Compose 720p H.264 MP4| FFmpeg[Native FFmpeg Worker Engine]
    IsolatedInstance -->|Upload Rendered MP4| SupaStorage
    IsolatedInstance -->|Update Job & Media Records| SupaDB[(Supabase PostgreSQL)]
    IsolatedInstance -->|Idle Timeout| ScaleZero[Scale to 0 Replicas (₹0.00 Idle Cost)]
```
