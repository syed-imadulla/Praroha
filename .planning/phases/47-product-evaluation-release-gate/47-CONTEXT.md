# Phase 47 Context: Product Evaluation & Release Gate

## Overview
Phase 47 serves as the formal release gate for Milestone 6: Core Product Intelligence & Media Reliability.
It establishes empirical, un-mocked proof that PRAROHA satisfies its core purpose (*Tatva 2: Forms Hidden in Formless*) while upholding strict credit protection, persistent memory, and production reliability.

## Acceptance Pillars
1. **Arbitrary Seed Divergence**:
   - Proof that completely un-primed creative seeds (Seed X vs Seed Y) generate fundamentally divergent worlds and universe codexes without converging into boilerplate tropes.
2. **Creative Memory & Lore Consistency**:
   - Automated tests verifying that multi-scene unfolding and character dialogues adhere to World Bible physics, established motivations, and creator locks without hallucinated drift.
3. **Origin Trail & Controlled Regeneration**:
   - Verification that upstream changes trigger accurate blast radius previews (`AFFECTED`/`CONDITIONAL`/`PRESERVED`) and selective regeneration updates lineage without damaging approved work.
4. **Media Reliability & Cost Protection**:
   - Verification that composite providers halt immediately upon 402/403/429 errors without blind cascading.
   - Verification that duplicate generation requests return cached assets via content hashes.
5. **Durable Cloud Architecture**:
   - Verification that generation jobs survive container restarts and browser disconnects.
   - Verified operation across the live Azure Container Apps backend, Vercel PWA frontend, and Supabase cloud services.
6. **Live vs Mock Evidence Segregation**:
   - Strict separation of live provider verification tests from deterministic offline mock tests.
   - Real proof documented with genuine HTTP logs and response hashes.
