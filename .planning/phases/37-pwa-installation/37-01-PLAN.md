# Plan 37-01: PWA Installation & Offline Behaviour

## Objective
Convert PRAROHA into an installable, high-performance Progressive Web App (PWA) adhering to editorial branding (Tatva 2: Forms Hidden in Formless), featuring reliable service worker caching for shell assets, automatic updates, and clear offline awareness.

## Proposed Changes
1. **Install `vite-plugin-pwa`**:
   - Install `vite-plugin-pwa` as a devDependency in `frontend/package.json`.
2. **PWA Icons & Assets**:
   - Generate crisp PRAROHA leaf emblem icons in SVG and PNG format for:
     - `pwa-192x192.png`
     - `pwa-512x512.png`
     - `maskable-icon-512x512.png`
     - `favicon.svg` (brand green `#294B3A` and warm cream `#F8F4E8`).
3. **Vite PWA Configuration (`frontend/vite.config.ts`)**:
   - Configure `VitePWA` with manifest:
     - Name: `PRAROHA — Seed to Universe`
     - Short name: `PRAROHA`
     - Description: `Autonomous universe unfolding with initial agency. Forms hidden in formless.`
     - Theme color: `#294B3A`
     - Background color: `#F8F4E8`
     - Display: `standalone`
     - Orientation: `any`
     - Scope: `/`
     - Start URL: `/`
   - Cache static assets (HTML, CSS, JS, fonts, SVGs).
   - Exclude API endpoints (`/api/**`) and authenticated Supabase routes from caching.
4. **Offline Awareness Component (`frontend/src/components/OfflineBanner.tsx`)**:
   - Monitor `navigator.onLine` and `window.addEventListener('online'/'offline')`.
   - Render a discreet botanical warning banner when offline: "Offline Mode — Generative AI models and cloud synchronization require an internet connection."
5. **App Integration**:
   - Mount `OfflineBanner` inside `AppShell.tsx`.
   - Add PWA meta tags in `frontend/index.html`.
6. **Verification**:
   - Run `npm run build --prefix frontend` to generate service worker and manifest.
   - Verify `dist/sw.js` and `dist/manifest.webmanifest`.
   - E2E test verifying manifest and service worker registration.
