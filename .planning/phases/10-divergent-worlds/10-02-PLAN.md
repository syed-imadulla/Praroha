# Phase 10 Plan 2 (10-02-PLAN.md): Frontend Divergent Worlds UI & E2E Verification

## Goal
Implement frontend components, metrics meters, archetype badges, and potential pills for the Divergent Worlds Engine across Stage 3 (Candidates) and Stage 4 (Selection), verified by an automated Playwright E2E test suite.

---

## Requirements Addressed
- **DIV-01**: Visually present exactly three distinct exploration archetypes (`Familiar`, `Radical`, `Inverse`) with dedicated styling and badge banners.
- **DIV-02**: Render the AI-generated Exploration Profile with four color-coded horizontal progress meters (Seed Fidelity, Novelty, Conceptual Distance, Feasibility: 0–100%) and summary callouts.
- **DIV-03**: Display emphasized Seed Potential pills directly on candidate cards, showing how accepted items shaped each world.

---

## Proposed Changes

### 1. Types (`frontend/src/types/index.ts`)
- Add `DivergenceArchetype = 'familiar' | 'radical' | 'inverse'`.
- Add `ExplorationProfile` interface:
  - `seed_fidelity: number;`
  - `novelty: number;`
  - `conceptual_distance: number;`
  - `feasibility: number;`
  - `summary: string;`
- Extend `WorldCandidate` and `WorldCandidateRead` with:
  - `divergence_archetype?: DivergenceArchetype;`
  - `exploration_profile?: ExplorationProfile;`
  - `emphasized_potential_labels?: string[];`

### 2. Candidate Card (`frontend/src/components/WorldCandidateCard.tsx`)
- Archetype Banner Pill:
  - Add visual header pill dynamically tailored to the candidate's archetype:
    - `familiar`: Cyan theme (`Familiar • Grounded Archetype`)
    - `radical`: Emerald / Violet theme (`Radical • Paradigm Shift`)
    - `inverse`: Amber / Rose theme (`Inverse • Conceptual Subversion`)
- Exploration Profile Meters:
  - Render an interactive "Exploration Profile" section with 4 mini horizontal bars:
    - **Seed Fidelity**: Cyan bar (`bg-cyan-500`), percentage text, tooltip explaining alignment with seed anchors.
    - **Novelty**: Violet bar (`bg-violet-500`), percentage text, tooltip explaining conceptual uniqueness.
    - **Conceptual Distance**: Rose bar (`bg-rose-500`), percentage text, tooltip explaining departure from genre tropes.
    - **Feasibility**: Emerald bar (`bg-emerald-500`), percentage text, tooltip explaining narrative stability.
  - Render `exploration_profile.summary` in a subtle italic caption.
- Emphasized Potential Pills:
  - Render a small list of badges for `emphasized_potential_labels`:
    - E.g. `+ Sunken Metropolis`, `+ Ancient Symbiotic Technology`.
    - Styled with subtle glow and `Sparkles` icon to show the explicit bridge from Stage 9.

### 3. Stage 3 Canvas (`frontend/src/components/WorldCandidatesCanvas.tsx`)
- Add an Archetype Triad indicator in the stage header showing:
  - `1 Familiar` • `1 Radical` • `1 Inverse` balanced distribution.
- Ensure loading state reflects "Synthesizing Divergence Triad (Familiar / Radical / Inverse)...".

### 4. Stage 4 Selection Canvas (`frontend/src/components/WorldSelectionCanvas.tsx`)
- Ensure selected world details in the summary column display the archetype pill and exploration profile metrics so the creator clearly understands the trade-offs of their chosen direction before committing.

### 5. Automated E2E Verification (`frontend/e2e/test_phase10_divergence.cjs`)
- Run headless browser test verifying:
  - Canonical demo load.
  - Stage 3 candidate cards display all 3 archetypes: `Familiar`, `Radical`, and `Inverse`.
  - Exploration profile progress meters (Fidelity, Novelty, Conceptual Distance, Feasibility) render valid width percentages.
  - Emphasized potential pills are visible on cards.
  - Proceeding to Stage 4 preserves archetype details on selection.
  - Captures visual proof screenshots to `artifacts` directory.

---

## Verification Criteria
- `npm run build` passes with zero TypeScript or bundle errors.
- `node frontend/e2e/test_phase10_divergence.cjs` passes 100%.
- Both Stage 3 and Stage 4 seamlessly display divergence archetypes and exploration profiles.
