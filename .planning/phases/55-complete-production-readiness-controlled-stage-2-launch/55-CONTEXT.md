## 4. Retention Policy & Architecture
- **Implementation**: `backend/app/services/cinematic_retention_sweeper.py`.
- **Core Rules**:
  - Default age threshold: 60 days.
  - Safe default: Dry-run mode (`dry_run=True`), zero deletions unless explicitly flagged.
  - Scope isolation: Strictly targets `media_type='video'` and `provider_name='Cinematic Preview'`. User media, original uploads, and non-cinematic assets are excluded.
  - Active preview preservation: Completed primary previews belonging to non-deleted projects are NEVER purged.
  - Execution Cadence: Integrated into backend background lifecycle or executed via bounded daily task.

## 5. Security & Public Video URL Model
- Video assets generated by the cinematic pipeline are uploaded to the Supabase storage bucket (`seed-unfold-assets`).
- URLs are constructed using unguessable UUIDv4 file names and paths (`projects/{project_id}/media/video/{entity_id}_{timestamp}.mp4`).
- Supabase bucket is public-read to enable low-latency CDN streaming without complex signed token rotations.
- Authorization boundary is strictly enforced at job dispatch, polling, and metadata retrieval endpoints.
- Unauthenticated requests are rejected (HTTP 401).
- Cross-owner requests are rejected (HTTP 403 / 404).
