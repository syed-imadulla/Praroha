# Plan 35-01: Real Video Generation & Provider Transparency

## Objective
Establish a viable, genuine video generation route with background jobs, progress tracking, cost/duration guards, durable media storage, and playable video playback. Provide honest status badges differentiating real live AI generation from synthetic offline MP4 previews.

## Tasks
1. Audit and Harden Backend Video Providers:
   - Update `backend/app/providers/media/pyramid_flow.py`:
     - Update URL to modern Hugging Face router conventions (`https://router.huggingface.co/models/pyr-flow/pyramid-flow`).
     - Detect HTTP 401/403/429 and return actionable provider unavailable errors.
     - Add `is_synthetic: False` and `provider_label: "Pyramid Flow"` to metadata.
   - Update `backend/app/providers/media/wan.py`:
     - Validate endpoint connectivity and timeouts.
     - Add `is_synthetic: False` and `provider_label: "Wan 2.1"` to metadata.
   - Update `backend/app/providers/media/composite_video.py`:
     - In real production mode (`ENVIRONMENT != 'demo'`), fail honestly with descriptive `ProviderUnavailableError` if endpoints/tokens are unconfigured.
     - In demo/offline mode, deliver deterministic ISO BMFF MP4 marked explicitly with `is_synthetic: True` and `provider_label: "Synthetic Preview"`.
2. Enhance Frontend Video Display:
   - Update `MediaPreviewCard.tsx` video player:
     - Render distinct botanical status badge: `[Synthetic Preview]` with tooltip when using offline fallback, or `[Live Pyramid Flow]` / `[Live Wan 2.1]` when live model generates.
     - Ensure video player correctly handles play/pause, volume, seeking, theater lightbox, and download across reloads.
3. Verification & Testing:
   - Run `pytest backend/tests/test_video_generation.py`.
   - Run `npm run build --prefix frontend`.
   - Write phase summary and verification reports.
