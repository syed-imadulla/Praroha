# Phase 31.1: Gemini & AI Provider Repair Plan

## 1. Objective

Repair live AI generation so that arbitrary seeds produce genuine, divergent outputs from Google Gemini without silent mock fallbacks.
Eliminate the silent fallback mask where failed Gemini calls reverted to the canonical Sunken Ocean City fixtures.
Ensure production failures return explicit HTTP 502/503 errors with actionable error codes and retry semantics.

---

## 2. Requirements Addressed

- **REAL-01.1**: Active valid Gemini model (`gemini-3.6-flash` with dynamic fallback to `gemini-3.1-flash-lite` on transient 503) verified against live Google AI API.
- **REAL-01.2**: Complete removal of silent fallback to `MockProvider` for production user generation.
- **REAL-01.3**: Arbitrary creative seeds produce materially different Seed DNA, Potential items, and World candidates (verified with Seed A vs Seed B).
- **REAL-01.4**: If the provider fails, return explicit error envelope with error code, message, and `retryable: true`.

---

## 3. Architecture & Code Changes

### 3.1. `backend/app/config.py`
- Update `GEMINI_MODEL: str = "gemini-3.6-flash"`.
- Add `GEMINI_FALLBACK_MODELS: List[str] = ["gemini-3.1-flash-lite", "gemini-flash-lite-latest"]`.
- Ensure `AI_PROVIDER: str = "gemini"` when `GEMINI_API_KEY` is present.

### 3.2. `backend/app/providers/gemini_provider.py`
- Define custom exception `AIProviderError(Exception)` with `status_code`, `error_code`, `message`, and `retryable`.
- Implement resilient model failover: try `self.model` (`gemini-3.6-flash`); on HTTP 503 (high demand) or 429, attempt fallback to `gemini-3.1-flash-lite`.
- In `extract_dna`, `extract_potential`, `generate_worlds`, `unfold_universe`, `refine_component`, `synthesize_causal_diff`, `simulate_counterfactual_delta`:
  - When live API fails, do NOT call `_mock_provider`.
  - Raise `AIProviderError`.
  - Only route to `_mock_provider` when explicitly instantiated in mock mode or `is_demo=True`.

### 3.3. Router Error Handling (`dna.py`, `worlds.py`, `unfold.py`, `potential.py`)
- Catch `AIProviderError` and return standardized error response:
  ```json
  {
    "status": "error",
    "error_code": "AI_GENERATION_FAILED",
    "message": "AI generation failed: ...",
    "retryable": true
  }
  ```
  with HTTP 502 Bad Gateway or 503 Service Unavailable.

### 3.4. Verification Suite (`backend/tests/test_real_ai_provider.py`)
- Test live generation with Seed A: *"A nomadic clockmaker wandering a desert of calcified glass"*.
- Test live generation with Seed B: *"A silent monastery orbiting a dying white dwarf star"*.
- Assert Seed A premise != Seed B premise.
- Assert neither Seed A nor Seed B contains *"Sunken Ocean City"*, *"Aethelgard"*, or *"Aquatica"*.
- Test error behavior when API key is invalid or API is blocked (must raise error, not return mock data).

---

## 4. Verification & Success Criteria

1. `python3 -m pytest backend/tests/test_real_ai_provider.py -v` passes 100%.
2. Existing 154 backend tests in `backend/tests/` continue to pass without regressions.
3. Live API call produces real, divergent outputs.
