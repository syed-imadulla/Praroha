# Phase 12 Plan 2 (12-02-PLAN.md): Frontend Origin Ledger UI & E2E Suite

## Goal
Implement interactive Origin Badges across all Universe Codex cards (Characters, Locations, Scenes, Rules), build the deterministic "Why is this here?" explainer modal, add Origin filtering to both the Causal Lineage DAG and Codex views, display origin breakdown metrics in the Inspector Drawer, and verify all flows with an automated Playwright E2E suite.

---

## Requirements Addressed
- **ORIG-01**: User-facing origin classification badges across all universe entities.
- **ORIG-02**: Causal Lineage DAG integrates origin metadata badges, color accents, and interactive filtering.
- **ORIG-03**: "Why is this here?" drawer and card modal interactions provide human-intelligible causal provenance based on stored metadata.

---

## Technical Tasks

### 1. Types & Design Tokens (`frontend/src/types/index.ts`)
- Define `OriginType`:
  ```typescript
  export type OriginType =
    | 'SEED_EXPLICIT'
    | 'SEED_INFERRED'
    | 'HUMAN_DECISION'
    | 'DERIVED'
    | 'AI_INTRODUCED'
    | 'USER_ADDED';
  ```
- Extend `Character`, `Scene`, `Location`, and `TraceNode` interfaces with:
  ```typescript
  origin_type?: OriginType;
  origin_source?: string | null;
  ```

### 2. Reusable Components
- Create `frontend/src/components/OriginBadge.tsx`:
  - Renders compact, clickable origin badge with icons and styling:
    - `SEED_EXPLICIT`: Cyan badge + Anchor icon
    - `SEED_INFERRED`: Indigo badge + Sparkles icon
    - `HUMAN_DECISION`: Amber badge + Compass/Lock icon
    - `DERIVED`: Sky badge + GitFork icon
    - `AI_INTRODUCED`: Violet badge + Bot/Wand icon
    - `USER_ADDED`: Emerald badge + UserCheck icon
  - Supports `interactive?: boolean` (click triggers "Why is this here?" explainer modal).
  - Clean tooltips explaining the origin category.
- Create `frontend/src/components/WhyIsThisHereModal.tsx`:
  - Floating glassmorphism modal / slide-over displaying:
    - Entity Title & Type
    - Origin Classification Badge
    - Exact Origin Anchor / Source citation
    - Plain-Language Causal Justification narrative
    - Parent Ancestor Link button (jumps directly into Stage 6 Trace DAG)

### 3. Universe Codex Canvas (`frontend/src/components/UniverseCodexCanvas.tsx`)
- Add Origin Filter Toolbar at the top of the Codex:
  - `[All (N)] [Seed Explicit] [Human Decision] [Seed Inferred] [Derived] [AI Introduced] [User Added]`
- Embed `OriginBadge` in:
  - Character Cards (header right, beside archetype)
  - Location Cards (beside location name)
  - Scene Cards (beside scene index/title)
  - Canon Facts / Rules (beside fact bullet)
- Wire clicking any `OriginBadge` to open `WhyIsThisHereModal`.

### 4. Causal Lineage DAG Canvas (`frontend/src/components/TraceabilityCanvas.tsx`)
- Update `NodeCard`:
  - Render `OriginBadge` at top-right of each node card.
  - Apply subtle glowing border matching the node's `origin_type`.
- Add Origin Filter toolbar to DAG controls:
  - Allows creators to isolate nodes by origin (e.g., show only `HUMAN_DECISION` and `SEED_EXPLICIT` nodes).
- Update right-side Causal Inspector card (`#causal-inspector-card`):
  - Render detailed Origin Ledger section with `origin_type`, `origin_source`, and structured causal breakdown.

### 5. Inspector Drawer Lineage Integration (`frontend/src/components/InspectorDrawer.tsx`)
- In Lineage tab (Step 5 node and header):
  - Add Origin Ledger distribution bar (displaying counts or % breakdown of each origin type).

### 6. Automated Playwright E2E Suite (`frontend/e2e/test_phase12_origin_ledger.cjs`)
- Scenario 1: Load Canonical Demo Universe and verify Origin Badges render across Characters, Locations, and Scenes in Codex.
- Scenario 2: Click "Why is this here?" on Dr. Althea Thorne card and verify deterministic explanation modal content.
- Scenario 3: Navigate to Stage 6 Traceability DAG and verify origin badges and border accents on DAG nodes.
- Scenario 4: Use Origin Filter toolbar to isolate `HUMAN_DECISION` nodes.
- Scenario 5: Verify Lineage Inspector displays Origin Ledger metrics and ancestor provenance trail.
