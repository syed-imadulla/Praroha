# Phase 12 Plan 1 (12-01-PLAN.md): Backend Origin Ledger Engine

## Goal
Implement the 6-tier **Universal Origin Classification Taxonomy** (`ORIG-01`), extend entity data models and database schemas with backward-compatible migrations, update `LineageService` to populate origin classifications across all DAG nodes, and build a deterministic "Why is this here?" causal explainer generator (`ORIG-03`), validated by a dedicated Pytest test suite.

---

## Requirements Addressed
- **ORIG-01**: Every universe entity (character, rule, location, scene) is tagged with an origin classification (`SEED_EXPLICIT`, `SEED_INFERRED`, `HUMAN_DECISION`, `DERIVED`, `AI_INTRODUCED`, `USER_ADDED`).
- **ORIG-02**: Causal Lineage DAG integrates origin metadata on all nodes and relationships.
- **ORIG-03**: "Why is this here?" causal explanation synthesized deterministically from stored metadata without exposing raw LLM reasoning tokens.

---

- Define `OriginType` literal/type:
  ```python
  OriginType = Literal[
      "SEED_EXPLICIT",
      "SEED_INFERRED",
      "HUMAN_DECISION",
      "DERIVED",
      "AI_INTRODUCED",
      "USER_ADDED",
  ```

  - `SceneBase` & `SceneRecord`:
