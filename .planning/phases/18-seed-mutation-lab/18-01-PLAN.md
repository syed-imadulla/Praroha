# Phase 18: Plan 1 (18-01-PLAN.md) — Backend Seed Mutation Engine & Branching Integration
**Status:** Completed ✅

## Wave 1: Backend Mutation Engine (Extraction, Lineage-First Simulation, Causal Classification & Branching)

### Goal
Implement the complete backend Seed Mutation Lab subsystem featuring structured premise variable extraction across all 4 variables, lineage-first downstream impact classification (`AFFECTED`, `CONDITIONAL`, `PRESERVED`) driven by `LineageService` and `OriginLedger`, zero-destruction timeline branching via `PersistenceService.branch_project`, project-level mutation metadata persistence, variable-specific entity adaptation in the child branch, Origin Ledger mutation citations, parent immutability verification, and a comprehensive pytest regression suite.

---

### Scope Boundaries & Non-Goals (Correction 8)
- **Strictly in Scope**:
  - All four premise variables (Core Premise, Tone & Atmosphere, Central Conflict, World Rule).
  - Lineage-first impact classification with deterministic offline fallback.
  - Zero-destruction branching with deep parent immutability and complete child ID remapping.
  - Project-level `mutation_metadata_json` persistence.
  - Standard Origin Ledger citation (`origin_type="USER_ADDED"`).
  - Sanitized branch naming with collision safety.
- **Strictly Out of Scope**:
  - Phase 19 Counterfactual Replay.
  - Phase 20 Human-Only Zones.
  - Timeline merging or git-style cherry-picking.
  - New graph database or microservices.
  - Automatic media regeneration (media remains non-blocking and optional).

#### 2. Implement Lineage-First Mutation Service (Corrections 1, 2, 3, 4, 6)
- **File**: `backend/app/services/mutation_service.py`
- **Responsibilities**:
  - `extract_premise_variables(project_id: str) -> List[PremiseVariableRead]`:
    - Fetches `SeedDNARecord`, `WorldBibleRecord`, and `WorldSelectionRecord`.
    - Returns all 4 variables:
      1. **Core Premise Assumption**: from `seed_dna.premise`
      2. **Tone & Atmosphere**: from `seed_dna.tone`
      3. **Central Thematic Conflict**: from `seed_dna.themes` / `selected_world.concept`
      4. **World Rule / Technological Foundation**: from `world_bible.physics_law` or core lore rule
  - `sanitize_branch_name(name: str, existing_branches: List[str]) -> str` (Correction 6):
    - Sanitizes special characters (allows alphanumeric, hyphen, underscore, slash).
    - Converts spaces to hyphens, lowercases, trims slashes.
    - Deterministic fallback for empty names: `mutation/unnamed-fork`.
    - Collision prevention: appends `-2`, `-3` if name collision exists, preventing silent overwrites.
  - `simulate_mutation(project_id: str, request: SeedMutationRequest) -> MutationSimulationResponse` (Correction 3):
    - **Lineage-First Classification**:
      - Priority 1: Traverse `LineageService` DAG from anchor node corresponding to the variable.
        - Direct descendants / tightly coupled nodes $\rightarrow$ `AFFECTED`.
        - Intermediate relational nodes, secondary character dynamics, and downstream scenes $\rightarrow$ `CONDITIONAL`.
        - Disconnected subgraphs (unrelated geography, ambient lore) $\rightarrow$ `PRESERVED`.
      - Priority 2: Origin Ledger anchor validation (`SEED_EXPLICIT` vs `DERIVED` vs `HUMAN_DECISION`).
      - Priority 3: Deterministic semantic fallback when graph edges are sparse, guaranteeing offline resilience.
    - Formulates user-facing causal justifications without chain-of-thought tokens.
  - `fork_mutated_universe(project_id: str, request: ForkMutationRequest) -> ProjectRead` (Corrections 1, 2, 4, 5, 6):
    - Sanitize requested branch name via `sanitize_branch_name`.
    - Execute `PersistenceService.branch_project` to clone parent into isolated child project with ID remapping.
    - **Persist Mutation Metadata (Correction 1)**:
      - Store serialized `MutationMetadata` in child `project.mutation_metadata_json`.
    - **Variable-Specific Adaptation Strategy (Correction 2)**:
      - If `mutated_variable == "core_premise"`:
        - Update `child_dna.premise = request.new_value`.
        - Adapt dependent World Bible summary, primary location, and world stakes.
      - If `mutated_variable == "tone_atmosphere"`:
        - Update `child_dna.tone = request.new_value`.
        - Adapt tone-sensitive narrative descriptors in World Bible, character demeanor, and scene mood.
      - If `mutated_variable == "central_conflict"`:
        - Incorporate conflict into `child_dna.themes_json`.
        - Adapt character motivations/conflicts (`char.motivation`, `char.core_conflict`) and scene dramatic questions.
      - If `mutated_variable == "world_rule"`:
        - Update `child_bible.physics_law = request.new_value`.
        - Adapt dependent locations (infrastructure, defenses) and scene setting dynamics.
    - **Origin Ledger Mutation Citation (Correction 4)**:
      - Adapted entities receive:
        - `origin_type = "USER_ADDED"`
        - `origin_source = f"Forked via Seed Mutation Lab: {request.hypothesis_prompt or request.new_value}"`
    - **Preserve `PRESERVED` entities**: Invariant entities remain untouched in the child branch.
    - **Parent Immutability (Correction 5)**: The parent project remains completely unmodified.
