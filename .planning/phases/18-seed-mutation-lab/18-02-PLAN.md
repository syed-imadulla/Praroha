# Phase 18: Plan 2 (18-02-PLAN.md) — Frontend Seed Mutation Lab & Causal Diff DAG
**Status:** Completed ✅

## Wave 2: Frontend Mutation Lab (Split-View Canvas, Causal Diff DAG, Branching UX & E2E Suite)

### Goal
Implement the frontend Seed Mutation Lab user interface featuring a split-view workspace: premise variable controls for all four variables, freeform "What If?" statement prompt, and downstream Impact Matrix on the left; an interactive Causal Diff DAG with status color halos, propagation paths, and node detail popovers on the right; safe "Fork Mutated Universe" execution with instant branch switching; verification of parent universe immutability; and an automated Playwright E2E suite demonstrating the canonical weaponized-outpost mutation storyline.

---

### Scope Boundaries & Non-Goals (Correction 8)
- **Strictly in Scope**:
  - Premise variable selection across all 4 variables.
  - "What If?" hypothesis prompt + quick preset chips.
  - Impact Matrix with `AFFECTED`, `CONDITIONAL`, `PRESERVED` entity cards and plain causal justifications.
  - Interactive Causal Diff DAG with amber/cyan/emerald status styling and animated ripple paths.
  - Safe branch creation, preview, auto-switching, and branch-switching back to original `main`.
  - Origin Ledger mutation citation surfacing in Lineage Inspector.
- **Strictly Out of Scope**:
  - Phase 19 Counterfactual Replay (candidate comparisons).
  - Phase 20 Human-Only Zones.
  - Timeline merging or git-style cherry-picking.
  - Automatic media regeneration (media remains non-blocking and optional).

#### 1. Define Frontend TypeScript Interfaces (Corrections 1, 2)
- **File**: `frontend/src/types/index.ts`
- **Types**:
  - `PremiseVariableType`: `'core_premise' | 'tone_atmosphere' | 'central_conflict' | 'world_rule'`
  - `PremiseVariable`:
    - `id: string`
    - `variable_type: PremiseVariableType`

    - `original_value: string`
    - `source_entity: string`
  - `SeedMutationRequest`:

    - `original_value: str`
    - `new_value: string`
    - `hypothesis_prompt?: string`
  - `EntityImpactCategory`: `'AFFECTED' | 'CONDITIONAL' | 'PRESERVED'`

    - `entity_id: string`

    - `title: string`
    - `impact_category: EntityImpactCategory`

    - `projected_impact: string`
    - `original_summary: string`
  - `MutationSimulationResponse`:
    - `project_id: string`
    - `mutated_variable: string`
    - `original_value: string`
    - `new_value: string`
    - `hypothesis_prompt?: string`
    - `suggested_branch_name: string`
    - `impacted_entities: EntityImpactItem[]`
    - `summary_counts: { affected: number; conditional: number; preserved: number }`
  - `ForkMutationRequest`:
    - `mutated_variable: string`

    - `hypothesis_prompt?: string`

#### 3. Implement Interactive Causal Diff DAG Component (Correction 3, 4)
- **File**: `frontend/src/components/MutationCausalDiffDAG.tsx`
- **Features**:
  - Interactive SVG DAG rendering nodes by creative tier (Seed DNA $\rightarrow$ World Bible $\rightarrow$ Characters $\rightarrow$ Scenes).
  - **Status Visual Encoding**:
    - `AFFECTED`: Warning amber-red halo (`border-amber-500`, amber glow `shadow-[0_0_15px_rgba(245,158,11,0.35)]`, badge `AFFECTED`).
    - `CONDITIONAL`: Cyan adaptation border (`border-cyan-400`, cyan tint, badge `CONDITIONAL`).
    - `PRESERVED`: Emerald calm border with lock icon (`border-emerald-500/50`, emerald tint, badge `PRESERVED`).
  - **Animated Propagation Paths**:
    - Glowing animated SVG paths flowing from the mutated Seed node down to affected and conditional nodes.
  - **Node Detail Popover / Inspection (`data-testid="dag-node-detail-panel"`)**:
    - Displays Entity Title, Type Badge, Impact Category.
    - Causal Justification (concise, user-facing, zero CoT).
    - Projected Mutation Impact.
    - Original Summary.
