# Phase 46: Cinematic Preview Proof of Concept

## Phase Goal
Evaluate HyperFrames programmatic video rendering against Azure Container Apps resource limits (0.5 vCPU, 1.0 GiB RAM), pilot an isolated preview worker, and maintain JSON2Video as the verified operational baseline with clear synthetic preview watermarking.

---

## Architecture Contract & Scope

```mermaid
graph TD
    Assets[Universe Assets: Concept Art, Voice MP3, Ambient WAV, Scene Script] --> PreviewRouter{Preview Mode Selector}
    PreviewRouter -->|Cloud API Baseline| JSON2Video[JSON2Video Composition Engine]
    PreviewRouter -->|Isolated Pilot| HyperFramesWorker[Standalone HyperFrames Worker Container]
    HyperFramesWorker --> ChromiumFFmpeg[Node / Chromium Headless / FFmpeg]
    ChromiumFFmpeg --> RenderedMP4[Cinematic Motion MP4]
    JSON2Video --> RenderedMP4
    RenderedMP4 --> Watermark[Watermark: is_synthetic=True, [Cinematic Preview]]
```

---

## Detailed Task Breakdown

### Wave 1: Technical & Licensing Feasibility Assessment
- [ ] **TASK-46-01**: Document HyperFrames licensing terms, repository structure, and external dependencies.
- [ ] **TASK-46-02**: Benchmark memory and CPU usage of Node.js + Chromium headless + FFmpeg execution in a 1.0 GiB RAM container environment.
- [ ] **TASK-46-03**: Assess render duration and timeout risks for 15-second cinematic motion preview clips.

### Wave 2: Isolated Preview Worker Pilot Specification
- [ ] **TASK-46-04**: Design isolated worker architecture: decouple preview rendering from the main FastAPI API container to prevent OOM termination of the web service.
- [ ] **TASK-46-05**: Specify scene composition template: pan/zoom across Pollinations concept art, synchronized Edge-TTS dialogue captions, and ambient audio background ducking.
- [ ] **TASK-46-06**: Ensure fallback to JSON2Video or static slideshow if the worker container reaches resource thresholds.

### Wave 3: Labeling Standards & Production Guardrails
- [ ] **TASK-46-07**: Enforce metadata requirement: all rendered outputs must have `is_synthetic: true` and `provider_label: "Cinematic Preview"`.
- [ ] **TASK-46-08**: Ensure the UI displays clear badges distinguishing composed previews from raw generative AI video.
- [ ] **TASK-46-09**: Write evaluation report `docs/CINEMATIC_PREVIEW_EVALUATION.md` documenting feasibility, cost, resource envelope, and recommendation for full production deployment.

---

## Verification & Acceptance Criteria
1. **Feasibility Report**: Document completed analyzing licensing, container RAM budget, render latency, and operational cost.
2. **Operational Baseline Protected**: JSON2Video remains 100% functional and untouched as the production preview route.
3. **Honest Labeling**: Composed footage is explicitly tagged with `is_synthetic: true` across all metadata responses.
4. **Zero Production Risk**: No heavy rendering libraries are installed into the primary ACA backend container.
