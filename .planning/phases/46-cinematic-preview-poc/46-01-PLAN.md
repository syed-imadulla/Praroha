# Phase 46: Cinematic Preview Proof of Concept

## Phase Goal
Evaluate HyperFrames programmatic video rendering against Azure Container Apps resource limits (0.5 vCPU, 1.0 GiB RAM) and pilot an isolated preview worker to establish a self-contained cinematic preview engine with clear synthetic preview watermarking following the removal of unreliable external video APIs.

---

## Architecture Contract & Scope

```mermaid
graph TD
    Assets[Universe Assets: Concept Art, Voice MP3, Ambient WAV, Scene Script] --> HyperFramesWorker[Standalone HyperFrames Worker Container]
    HyperFramesWorker --> ChromiumFFmpeg[Node / Chromium Headless / FFmpeg]
    ChromiumFFmpeg --> RenderedMP4[Cinematic Motion MP4]
    RenderedMP4 --> Watermark[Watermark: is_synthetic=True, [Cinematic Preview]]
```

## Detailed Task Breakdown

### Wave 1: Technical & Licensing Feasibility Assessment
- [x] **TASK-46-01**: Document HyperFrames licensing terms, repository structure, and external dependencies.
- [x] **TASK-46-02**: Benchmark memory and CPU usage of Node.js + Chromium headless + FFmpeg execution in a 1.0 GiB RAM container environment.
- [x] **TASK-46-03**: Assess render duration and timeout risks for 15-second cinematic motion preview clips.

### Wave 2: Isolated Preview Worker Pilot Specification
- [x] **TASK-46-04**: Design isolated worker architecture: decouple preview rendering from the main FastAPI API container to prevent OOM termination of the web service.
- [x] **TASK-46-05**: Specify scene composition template: pan/zoom across Pollinations concept art, synchronized Edge-TTS dialogue captions, and ambient audio background ducking.
- [x] **TASK-46-06**: Ensure graceful fallback to static keyframe preview if the worker container reaches resource thresholds.

### Wave 3: Labeling Standards & Production Guardrails
- [x] **TASK-46-07**: Enforce metadata requirement: all rendered outputs must have `is_synthetic: true` and `provider_label: "Cinematic Preview"`.
- [x] **TASK-46-08**: Ensure the UI displays clear badges distinguishing composed previews from raw generative AI video.
- [x] **TASK-46-09**: Write evaluation report `docs/CINEMATIC_PREVIEW_EVALUATION.md` documenting feasibility, cost, resource envelope, and recommendation for full production deployment.

---

## Verification & Acceptance Criteria
1. **Feasibility Report**: Document completed analyzing licensing, container RAM budget, render latency, and operational cost.
2. **Safe Disabled Baseline Protected**: Production video actions remain gracefully disabled until worker is fully verified.
3. **Honest Labeling**: Composed footage is explicitly tagged with `is_synthetic: true` across all metadata responses.
4. **Zero Production Risk**: No heavy rendering libraries are installed into the primary ACA backend container.
