# Phase 14 Plan 2 (14-02-PLAN.md): Frontend Visual Experience & Lightbox Modal

## Goal
Implement the frontend visual generation experience (`IMG-03`), including an interactive **Image Lightbox Modal** (`ImageLightboxModal.tsx`), aspect ratio selection controls (`1:1`, `16:9`, `9:16`), visual generation integration across World Candidate cards, World Bible view, Character cards, and Scene keyframes, and an automated 5-scenario Playwright E2E verification suite.

---

## Requirements Addressed
- **IMG-03**: Frontend entity cards provide "Generate Visual" buttons with loading skeletons and image preview modals.

---

## Technical Tasks

### 1. Interactive Image Lightbox Modal (`frontend/src/components/ImageLightboxModal.tsx`)
- Implement `ImageLightboxModal`:
  - Full-screen modal overlay with dark backdrop blur.
  - High-resolution unconstrained image view.
  - Header with title, provider badge, dimensions, and aspect ratio pill.
  - Prompt inspector card showing the exact prompt used, with a 1-click clipboard copy button.
  - Direct download action button allowing the creator to save the asset locally.
  - Keyboard dismissal on `Escape` key and click-outside backdrop dismissal.

### 2. Aspect Ratio Controls & Lightbox Trigger (`frontend/src/components/EntityMediaSection.tsx` & `MediaPreviewCard.tsx`)
- In `EntityMediaSection.tsx`:
  - Add aspect ratio selector pill group (`1:1`, `16:9`, `9:16`) for image generation.
  - Allow creators to select the desired ratio before initiating generation.
- In `MediaPreviewCard.tsx`:
  - Add click handler on completed image cards to trigger `ImageLightboxModal`.
  - Add visual zoom hover cue and "Click to expand" tooltip.

### 3. World Candidate & World Bible Visual Generation
- In `frontend/src/components/WorldCandidateCard.tsx`:
  - Embed `EntityMediaSection` for generating a hero world cover (`16:9` landscape) for each candidate.
- In `frontend/src/components/UniverseCodexCanvas.tsx`:
  - In Tab 1 (World Bible & Locations), add visual generation for the selected world cover and locations.

### 4. Frontend Build Validation
- Run `npm run build --prefix frontend` to ensure strict TypeScript compilation and production bundle generation with zero warnings or errors.

### 5. Automated Playwright E2E Test Suite (`frontend/e2e/test_phase14_image_generation.cjs`)
- Implement 5 comprehensive E2E scenarios:
  1. **Scenario 1: World Cover Generation**:
     - Generates hero visual cover for a world candidate and verifies image preview.
  2. **Scenario 2: Character Portrait with Aspect Ratio Selector**:
     - Selects aspect ratio, generates character portrait, verifies image renders with proper metadata.
  3. **Scenario 3: Scene Keyframe Generation**:
     - Generates scene keyframe visual in Stage 5 Scenes tab.
  4. **Scenario 4: Interactive Lightbox Modal**:
     - Clicks generated image, verifies lightbox modal opens, prompt inspector displays enriched prompt, copy button works, and modal closes cleanly on `Escape` / close button.
  5. **Scenario 5: 3-Tier Fallback Resilience**:
     - Verifies system gracefully delivers fallback visual assets without freezing UI or throwing errors.
- Capture visual artifact screenshots for all scenarios.

---

## Verification Criteria
- `npm run build --prefix frontend` succeeds with 0 errors.
- `node frontend/e2e/test_phase14_image_generation.cjs` passes all 5 scenarios.
- All 5 artifact screenshots saved to the brain directory.
