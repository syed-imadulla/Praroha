# Phase 14 Plan 2 (14-02-PLAN.md): Frontend Visual Experience & Lightbox Modal

## Goal
Implement the frontend visual generation experience (`IMG-03`), including an interactive **Image Lightbox Modal** (`ImageLightboxModal.tsx`) that consumes persisted image metadata directly, aspect ratio selection controls (`1:1`, `16:9`, `9:16`), multi-entity visual generation integration across all four locked visual targets (World Candidate cards, World Bible view, Characters tab, Locations, and Scenes / Story Beats), and an automated Playwright E2E verification suite explicitly testing controls across all target entities.

---

## Requirements Addressed
- **IMG-03**: Frontend entity cards provide "Generate Visual" buttons with loading skeletons and image preview modals.

---

## Technical Tasks

### 1. Interactive Image Lightbox Modal (`frontend/src/components/ImageLightboxModal.tsx`)
- Implement `ImageLightboxModal`:
  - Full-screen modal overlay with dark backdrop blur.
  - High-resolution unconstrained image view.
  - **Direct Consumption of Persisted Metadata**:
    - Consumes persisted backend metadata from `MediaAssetRead` rather than inventing, estimating, or calculating values independently:
      - Dimensions: `{asset.width} × {asset.height}`
      - Aspect ratio: `{asset.aspect_ratio}`
      - Resolved provider badge: `{asset.provider_name}` (`pollinations`, `flux`, `mock`)
      - MIME type: `{asset.mime_type}`
      - Timestamps: formatted `{asset.completed_at}`
      - Entity context: `{asset.entity_type}: {asset.entity_id}`
    - Prompt inspector card showing the exact enriched prompt (`asset.prompt`) with a 1-click clipboard copy button.
  - Direct download action button allowing the creator to save the asset locally (`<a>` download or blob trigger).
  - Keyboard dismissal on `Escape` key and click-outside backdrop dismissal.

### 2. Aspect Ratio Controls & Lightbox Trigger (`frontend/src/components/EntityMediaSection.tsx` & `MediaPreviewCard.tsx`)
- In `EntityMediaSection.tsx`:
  - Add aspect ratio selector pill group (`1:1`, `16:9`, `9:16`) for image generation.
  - Allow creators to select the desired ratio before initiating generation.
  - Dispatches `aspect_ratio` and entity context in `generateMedia` request payload.
- In `MediaPreviewCard.tsx`:
  - On image card click, triggers `ImageLightboxModal` passing the complete persisted `MediaAssetRead` object.
  - Add visual zoom hover cue and "Click to expand" tooltip.

### 3. Multi-Entity Visual Generation Coverage: World Covers, Characters, Locations, and Scenes
- Explicitly integrate visual generation tasks for all four locked visual targets across their dedicated UI surfaces:
  1. **World Covers**:
     - **World Candidate cards** (`frontend/src/components/WorldCandidateCard.tsx`): Embed `EntityMediaSection` for generating a hero world cover (`16:9` landscape) for each candidate during Stage 3 world divergence.
     - **World Bible header** (`frontend/src/components/UniverseCodexCanvas.tsx` - Bible tab header): Display and allow generating/regenerating the hero cover banner for the active world.
  2. **Character Portraits**:
     - **Characters tab** (`frontend/src/components/UniverseCodexCanvas.tsx` - Characters tab): Embed `EntityMediaSection` inside each Character card for portrait concept art generation (`1:1` or `9:16`), coexisting seamlessly alongside existing voice synthesis controls.
  3. **Location Concepts**:
     - **World Bible Locations** (`frontend/src/components/UniverseCodexCanvas.tsx` - Locations grid in Bible tab): Embed `EntityMediaSection` in each Location card for architectural/environmental concept visual generation (`16:9` landscape).
  4. **Scene Keyframes**:
     - **Scenes / Story Beats tab** (`frontend/src/components/UniverseCodexCanvas.tsx` - Scenes tab): Embed `EntityMediaSection` in each Scene/Story Beat card for cinematic keyframe generation (`16:9`) alongside scene audio narration controls.

### 4. Frontend Build Validation
- Run `npm run build --prefix frontend` to ensure strict TypeScript compilation and production bundle generation with zero warnings or errors.

### 5. Automated Playwright E2E Test Suite (`frontend/e2e/test_phase14_image_generation.cjs`)
- Implement comprehensive E2E test suite explicitly verifying generation controls and visual rendering across all locked entity types:
  1. **Scenario 1: World Cover Generation (World Candidates & World Bible)**:
     - Generates hero visual cover on a World Candidate card and verifies rendered preview in candidate card and World Bible header.
  2. **Scenario 2: Character Portrait Generation Controls & Rendering**:
     - Navigates to Codex Characters tab.
     - Verifies actual generation controls exist on Character cards.
     - Selects aspect ratio (`1:1` or `9:16`), clicks "Generate Visual", and verifies character portrait renders.
  3. **Scenario 3: Location Concept Generation Controls & Rendering**:
     - Navigates to World Bible Locations section.
     - Verifies actual generation controls exist on Location cards.
     - Clicks "Generate Visual", selects `16:9` ratio, and verifies location concept visual renders.
  4. **Scenario 4: Scene Keyframe Generation Controls & Rendering**:
     - Navigates to Story Beats / Scenes tab.
     - Verifies actual generation controls exist on Scene cards.
     - Clicks "Generate Visual" with `16:9` ratio, and verifies scene keyframe renders.
  5. **Scenario 5: Interactive Lightbox Modal Consuming Persisted Metadata**:
     - Clicks a generated visual card to launch `ImageLightboxModal`.
     - Asserts lightbox displays persisted metadata: dimensions (`width` × `height`), aspect ratio pill, provider badge, MIME type, and enriched prompt.
     - Verifies copy prompt action and `Escape` keyboard dismissal.
  6. **Scenario 6: 3-Tier Fallback Resilience**:
     - Verifies UI receives fallback asset (Flux/Mock) cleanly without throwing errors or blocking the canvas.
- Capture visual artifact screenshots for all scenarios.
