# Phase 14 Plan 1 (14-01-PLAN.md): Backend Image Provider Engine

## Goal
Implement the concrete **Image Generation Provider Engine** (`IMG-01`), including `PollinationsImageProvider` (primary keyless cloud generator), `FluxSchnellProvider` (local inference fallback), a 3-tier fallback orchestrator (`Pollinations` $\rightarrow$ `Flux` $\rightarrow$ `Mock`), prompt enrichment with universe `SeedDNA` visual context, storage metadata tracking (`IMG-02`), and a comprehensive Pytest test suite.

---

## Requirements Addressed
- **IMG-01**: Concrete `PollinationsProvider` as primary image generator (world covers, character portraits, scene visuals) where usable free/team path is available; with local FLUX.1 schnell fallback where practical, and `MockMediaProvider` as fallback of last resort.
- **IMG-02**: Generated image assets are stored via `StorageProvider` (Supabase Storage / local uploads) with metadata tracking.

---

## Technical Tasks

### 1. Concrete Pollinations Image Provider (`backend/app/providers/media/pollinations.py`)
- Implement `PollinationsImageProvider(ImageProvider)`:
  - Base URL: `https://image.pollinations.ai/prompt/{encoded_prompt}`
  - Dynamic resolution based on `aspect_ratio`:
    - `1:1`: $1024 \times 1024$
    - `16:9`: $1280 \times 720$
    - `9:16`: $720 \times 1280$
  - Query parameters:
    - `width`, `height`, `model="flux"`, `seed`, `nologo=true`
  - Uses `httpx.AsyncClient(timeout=25.0, follow_redirects=True)`.
  - Parses binary response (`image/jpeg` or `image/png`), generates unique filename, and returns `MediaPayload`.
  - Implements `health_check()`.

### 2. Local FLUX.1 schnell Provider (`backend/app/providers/media/flux.py`)
- Implement `FluxSchnellProvider(ImageProvider)`:
  - Checks if `FLUX_ENDPOINT` environment variable is configured (e.g. local ComfyUI/Diffusers service).
  - If unset or unreachable, raises `ProviderUnavailableError` allowing immediate cascade to Tier 3 mock.
  - If configured, dispatches POST request with prompt and dimensions.
  - Implements `health_check()`.

### 3. 3-Tier Composite Image Provider (`backend/app/providers/media/composite.py`)
- Implement `CompositeImageProvider(ImageProvider)`:
  - Encapsulates:
    - Tier 1: `PollinationsImageProvider`
    - Tier 2: `FluxSchnellProvider`
    - Tier 3: `MockImageProvider`
  - `generate_image()` execution flow:
    - Attempts Tier 1 (`Pollinations`).
    - On timeout or network failure, attempts Tier 2 (`Flux`).
    - On failure, silently and reliably delivers Tier 3 (`MockImageProvider`).
  - Records active provider in `MediaPayload.metadata["resolved_provider"]`.

### 4. Prompt Enrichment Engine (`backend/app/services/media_service.py`)
- Update `MediaService`:
  - When generating image, fetches project `SeedDNA` via `repo.get_seed_dna(project_id)`.
  - Prepends atmospheric and aesthetic framing:
    - `Tone: {dna.tone}`
    - `Style: {', '.join(dna.domain_keywords[:3])}`
  - Attaches enriched prompt to generation context and updates `MediaAssetRecord.prompt`.

### 5. Media Factory Updates (`backend/app/providers/media/factory.py`)
- Update `MediaProviderFactory.get_image_provider()`:
  - Resolves `CompositeImageProvider` by default when `IMAGE_PROVIDER` is unset or set to `pollinations`.
  - Resolves `MockImageProvider` when `IMAGE_PROVIDER=mock`.

### 6. Pytest Verification Suite (`backend/tests/test_image_generation.py`)
- Test cases:
  1. `test_pollinations_url_and_parameters`: Verifies dimensions, seed, and query params.
  2. `test_pollinations_mock_http_success`: Simulates successful HTTP 200 JPEG response.
  3. `test_3_tier_fallback_cascade`: Tests simulated Pollinations failure cascading to MockImageProvider without throwing exceptions.
  4. `test_prompt_enrichment`: Verifies Seed DNA tone and visual keywords are included.
  5. `test_image_api_with_aspect_ratios`: Tests REST API invocation with `1:1`, `16:9`, `9:16`.
  6. Regression test: Runs full `backend/tests/` suite (86+ tests) to verify 100% pass rate.
