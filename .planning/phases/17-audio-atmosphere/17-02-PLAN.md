## Wave 2: Frontend Audio Experience, Atmosphere Deck, Smart Ducking & E2E Verification

### Goal
Implement the frontend Audio & Atmosphere experience including curated mood presets, rich in-card audio players, persistent docked `AtmosphereDeck`, reference-counted multi-blocker audio ducking, user volume intent preservation, clean production build, and exhaustive Playwright E2E verification.

#### 2. Update Workspace Store with Atmosphere Deck & Category Blocker Set
- **File**: `frontend/src/store/workspaceStore.ts`
- **Responsibilities**:
  - State fields:
    - `activeAtmosphereAsset: MediaAsset | null`
    - `isAtmospherePlaying: boolean`
    - `atmosphereMasterVolume: number` (default 0.75, range 0 to 1; strictly preserved during ducking)
    - `isAtmosphereMuted: boolean` (manual user mute intent; never automatically unmuted)
    - `activeMediaBlockers: Set<string>` (media category keys: `"voice"`, `"video"`)
  - Actions:
    - `setAtmosphereTrack(asset: MediaAsset)`
    - `playAtmosphere()`, `pauseAtmosphere()`, `toggleAtmospherePlay()`
    - `setAtmosphereMasterVolume(vol: number)`
    - `toggleAtmosphereMute()`
    - `registerMediaBlocker(category: string)`: Idempotently adds category key (`"voice"` or `"video"`) to `activeMediaBlockers`.
    - `unregisterMediaBlocker(category: string)`: Removes category key when inactive. Ducking clears if and only if `activeMediaBlockers.size === 0`.
    - `getEffectiveAtmosphereVolume(): number`: Computes reactive volume:
      - If `isAtmosphereMuted` $\rightarrow$ returns `0`.
      - Else if `activeMediaBlockers.size > 0` $\rightarrow$ returns `atmosphereMasterVolume * 0.2`.
      - Else $\rightarrow$ returns `atmosphereMasterVolume`.

#### 5. Wire Category Blocker Registration Across Voice & Video Players
- **Files**:
  - `frontend/src/components/MediaPreviewCard.tsx`
  - `frontend/src/components/VideoLightboxModal.tsx`
- **Responsibilities**:
  - In `NarrativeAudioPlayer` (voice narration):
    - Register category `"voice"` on play; unregister `"voice"` on pause/ended/unmount.
  - In `NarrativeVideoPlayer` & `VideoLightboxModal` (video clips):
    - Register category `"video"` on play; unregister `"video"` on pause/ended/unmount.
  - Guaranteed behavior:
    - Registering `"voice"` while already registered is idempotent.
    - If Voice ends while Video is still playing, `"video"` remains in Set $\rightarrow$ Atmosphere remains ducked.
    - If Video ends while Voice is still playing, `"voice"` remains in Set $\rightarrow$ Atmosphere remains ducked.
    - Ducking clears only when both categories are inactive (`activeMediaBlockers.size === 0`).

#### 7. Production Build & Automated Playwright E2E Suite
- **Files**:
  - Run `npm run build --prefix frontend`.
  - Create `frontend/e2e/test_phase17_audio_atmosphere.cjs`.
- **E2E Scenarios**:
  1. **Scenario 1: World Ambient Soundscape Generation & In-Card Player**:
     - Generates audio on World Cover, verifies completed card, provider badge, progress bar, time tracker, and download button with correct MIME extension.
  2. **Scenario 2: Scene Dramatic Underscore with Curated Mood Preset**:
     - Navigates to Story Beats / Scenes, selects mood preset (e.g. `tense-dramatic`), generates audio, verifies canonical scene prompt with selected tone.
  3. **Scenario 3: Custom Creator Acoustic Prompt Preservation**:
     - Dispatches custom acoustic prompt, verifies strict preservation in persisted asset.
  4. **Scenario 4: Persistent Atmosphere Deck, Multi-Stream Blocker Set Ducking & Real Audio Element Inspection**:
     - Sends world soundscape to Atmosphere Deck.
     - Adjusts master volume to custom value `0.35` (35%).
     - **Inspects DOM element directly**: `document.querySelector('[data-testid="atmosphere-deck-audio-element"]').volume`.
     - 0 blockers $\rightarrow$ `audio.volume` $\approx 0.35$ (tolerance $\pm 0.01$).
     - Voice narration starts (category `"voice"`) $\rightarrow$ `audio.volume` ducks to $\approx 0.07$ ($0.35 \times 0.2$).
     - Video playback starts (category `"video"`) while Voice is still playing $\rightarrow$ `audio.volume` **remains $\approx 0.07$**.
     - Voice narration ends while Video is still playing $\rightarrow$ `audio.volume` **remains $\approx 0.07$**.
     - Video playback ends (Set becomes empty) $\rightarrow$ `audio.volume` restores to $\approx 0.35$.
     - User toggles manual mute (`isMuted = true`) $\rightarrow$ `audio.volume` equals `0`.
     - Voice narration starts and ends $\rightarrow$ `audio.volume` **remains `0`**; stored master volume **remains `0.35`** (no automatic unmuting).
  5. **Scenario 5: Mock WAV Browser Playability & 3-Tier Fallback Cascade Verification**:
     - Forces ACE-Step and Stable Audio unavailable $\rightarrow$ Mock succeeds $\rightarrow$ Chromium `HTMLMediaElement` evaluates `audio.readyState >= 1`, `duration > 0`, `audio.error === null`.
