# Phase 40: Production Cloud Deployment (Azure + Vercel + Supabase)

## Phase Goal
Deploy PRAROHA as a verified, publicly accessible production application utilizing Azure Container Apps for the FastAPI backend, Vercel for the React/Vite/PWA frontend, and Supabase for persistent PostgreSQL, Object Storage, Authentication, and Realtime events.

---

## Architecture Contract

```mermaid
graph TD
    User([Browser / Mobile PWA]) -->|HTTPS: app.vercel.app| Vercel[Vercel Edge CDN - Frontend SPA]
    User -->|Supabase JWT / Auth| SupaAuth[Supabase Auth Engine]
    User -->|WebSockets: Realtime Events| SupaRT[Supabase Realtime Engine]
    Vercel -->|REST API: /api/*| AzureACA[Azure Container Apps - FastAPI Backend]
    AzureACA -->|Async SQLModel| SupaDB[(Supabase PostgreSQL Session Pooler)]
    AzureACA -->|Asset Persistence: WAV/MP4/JPEG| SupaStorage[Supabase Object Storage: seed-unfold-assets]
    AzureACA -->|Seed DNA & Worlds| Gemini[Google Gemini 3.1 Flash]
    AzureACA -->|Character Dialogue Voice| EdgeTTS[Edge-TTS Neural Voice]
    AzureACA -->|Concept Art Visuals| Pollinations[Pollinations.ai Free Tier]
    AzureACA -->|Cinematic Video Preview| JSON2Video[JSON2Video Preview Engine]
```
