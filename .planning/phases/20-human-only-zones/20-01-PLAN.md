# Phase 20: Plan 1 (20-01-PLAN.md) — Backend Human-Only Zones & AI Protection Engine
**Status:** Completed ✅

## Wave 1: Backend Human-Only Zones (Data Modeling, DB Migrations, Strict Prompt Invariance Contract, Schema Guard & Pytest Suite)

### Goal
Implement the complete backend subsystem for **Human-Only Zones (HOZ)** (`HOZ-01`, `HOZ-02`). Creators can lock core themes, protagonist motivations, and central conflicts before AI expansion begins. The subsystem stores these locked parameters inside `world_selections.human_only_zones_json`, integrates them into `DecisionDNA`, injects an immutable `=== IMMUTABLE HUMAN-ONLY ZONES (CREATOR LOCKS) ===` contract into Gemini's generation prompt, enforces zero AI deviation via a post-processing backend schema guard, tags downstream entities with `origin_type = 'HUMAN_DECISION'` in the Universal Origin Ledger and Causal Lineage DAG, seeds the canonical demo universe with rich Human-Only Zones, and verifies all behaviors with an extensive pytest suite.

---

### Scope Boundaries & Non-Goals
- **Strictly in Scope**:
  - `HumanOnlyZones` schema in `backend/app/models/selection.py` with fields: `core_theme`, `protagonist_motivation`, `central_conflict`, `is_locked`.
  - Database schema migration in `ProjectRepository._migrate_columns`: `ALTER TABLE world_selections ADD COLUMN human_only_zones_json TEXT`.
  - `DecisionDNA` extension with `human_only_zones: Optional[HumanOnlyZones] = None`.
  - `WorldSelectionCreate` and `WorldSelectionRecord.to_decision_dna` support for `human_only_zones`.
  - Layer 1 AI Defense: Strict prompt invariance contract formatting in `GeminiProvider.format_decision_dna_contract`.
  - Layer 2 AI Defense: Post-generation schema guard in `unfold` router/service ensuring protagonist motivation, lore facts, and story conflict match creator locks with 0 CoT leak.
  - Universal Origin Ledger tagging: entities derived from locked zones receive `origin_type = 'HUMAN_DECISION'` and `origin_source = 'Human-Only Zone: <field>'`.
  - Canonical Instant Demo project seeding update in `ProjectRepository.create_canonical_demo_project`.
  - Dedicated unit and integration tests in `backend/tests/test_human_only_zones.py`.
- **Strictly Out of Scope**:
  - Arbitrary custom lock keys outside the core three (`core_theme`, `protagonist_motivation`, `central_conflict`).
  - Frontend UI components (handled in Wave 2: `20-02-PLAN.md`).
  - Rewriting existing Stage 1–3 endpoints.

#### 2. Implement Dual-Layer AI Defense & Unfold Schema Guard
- **Files**:
  - `backend/app/providers/gemini_provider.py`
  - `backend/app/routers/unfold.py`
  - `backend/app/repositories/project_repo.py`
- **Responsibilities**:
  - **Layer 1: Prompt Invariance Contract**:
    - Update `GeminiProvider.format_decision_dna_contract(context)`:
      - Read `human_only_zones` from `context["decision_dna"]`.
      - Only if present AND `is_locked` is True:
        - Append exact block:
          ```text
          === IMMUTABLE HUMAN-ONLY ZONES (CREATOR LOCKS) ===
          The following parameters were locked by the human creator and are INVIOLABLE AXIOMS:
          - CORE THEME: {core_theme}
          - PROTAGONIST MOTIVATION: {protagonist_motivation}
          - CENTRAL CONFLICT: {central_conflict}
          STRICT ZERO-OVERRIDE RULE: You MUST construct all world bible lore, character motivations, and narrative beats strictly around these exact anchors. Do NOT alter, soften, replace, or reinterpret these locked principles.
          ==================================================
          ```
        - Ensure values are not silently transformed, escaped, or truncated.
        - Ensure 0 Chain-of-Thought (CoT) leakage in prompt instructions.
  - **Layer 2: Backend Schema Guard & Deterministic Post-Processing Enforcement**:
    - In `backend/app/routers/unfold.py` (and repo persistence):
      - Extract `human_only_zones` from selection's `DecisionDNA`.
      - If `human_only_zones` and `human_only_zones.is_locked`:
        - **Core Theme Immutability**: Ensure world bible core premise rule / primary lore fact matches `human_only_zones.core_theme` verbatim; stamp with `origin_type = "HUMAN_DECISION"`, `origin_source = "Human-Only Zone: Core Theme"`.
        - **Protagonist Motivation Immutability**: Verify and overwrite lead protagonist character's motivation to match `human_only_zones.protagonist_motivation` verbatim; stamp with `origin_type = "HUMAN_DECISION"`, `origin_source = "Human-Only Zone: Protagonist Motivation"`.
        - **Central Conflict Immutability**: Verify and overwrite primary dramatic climax scene's conflict to match `human_only_zones.central_conflict` verbatim; stamp with `origin_type = "HUMAN_DECISION"`, `origin_source = "Human-Only Zone: Central Conflict"`.
      - Do NOT rely solely on LLM compliance: prove that even if Gemini/MockProvider hallucinates or drifts, the backend schema guard deterministically restores the creator's exact locked values.
      - Zero CoT leakage: all narrative justifications remain clean prose.
