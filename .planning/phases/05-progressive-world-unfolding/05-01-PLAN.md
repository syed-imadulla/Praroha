  1. Create `backend/app/routers/unfold.py`:
     - `POST /api/projects/{project_id}/unfold`:
       - Validate project exists (404).
       - Concurrency & Status Validation:
         - If `project.status == "unfolding"`:
           - Reject with HTTP 409 Conflict: `detail="Universe unfolding is already in progress for this project."`. (Do NOT treat unfolding as a retryable starting state).
         - If `project.status == "universe_unfolded"`:
           - Idempotency guard: return existing unfolded codex via `repo.get_unfolded_universe(project_id)` with `APIResponse[UnfoldedUniverseRead]` (prevents double-clicks from running duplicate generation or raising confusing errors).
         - If `project.status != "world_selected"`:
           - Reject with HTTP 400 Bad Request: `detail=f"Project must be in 'world_selected' status to begin unfolding. Current status: '{project.status}'."`.
       - Validate project has `selected_world_id` and fetch selected `WorldCandidateRecord`.
       - Fetch `SeedDNARecord` and creator rationale from active `WorldSelectionRecord`.
       - Set `project.status = "unfolding"`, commit state.
       - Assemble context with normalized immutable raw seed:
         `{ "raw_seed": project.original_seed, "seed": project.original_seed, "seed_dna": dna.to_read_schema().model_dump(), "selected_world": candidate.to_read_schema().model_dump(), "creator_rationale": selection.user_rationale if selection else None }`.
       - In `try / except`:
         - Call `provider.unfold_universe(context)`.
         - Call `repo.save_unfolded_universe(project_id, candidate.id, unfolded_data)`.
         - Return `APIResponse[UnfoldedUniverseRead]`.
       - On `Exception as e`:
         - Reset `project.status = "world_selected"`.
         - Commit project status reset (preserving selected_world_id and rationale so creator can safely retry).
         - Raise `HTTPException(status_code=status.HTTP_500_INTERNAL_SERVER_ERROR, detail=f"Unfold generation failed: {str(e)}")`.
     - `GET /api/projects/{project_id}/unfolded`:
       - Retrieve unfolded universe from repo.
       - If None, raise HTTP 404 with detail `"Universe has not been unfolded yet"`.
       - Return `APIResponse[UnfoldedUniverseRead]`.
  2. Mount `unfold_router` in `backend/app/main.py` under `/api`.
