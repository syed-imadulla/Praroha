     - Enforces the 4-step validation rules:
       1. Candidate exists: query `WorldCandidateRecord` by `candidate_id` (raise KeyError / ValueError if not found).
       2. Candidate belongs to project: verify `candidate.project_id == project_id` (raise ValueError if mismatch).
       3. Candidate's batch_id matches project's LATEST world-generation batch:
          - Query the latest batch_id: `select(WorldCandidateRecord.batch_id).where(WorldCandidateRecord.project_id == project_id).order_by(WorldCandidateRecord.created_at.desc()).limit(1)`.
          - If `candidate.batch_id != latest_batch_id`, reject by raising `ValueError("Candidate belongs to an older generation batch. Only candidates from the latest batch can be selected.")`.
       4. If all validations pass, proceed with selection.
     - Creates new `WorldSelectionRecord` with `batch_id = candidate.batch_id` and optional `user_rationale`.
     - Appends/preserves selection records in `world_selections` table.
     - Updates `project.selected_world_id = candidate_id` and `project.status = "world_selected"`.
     - Commits session and returns refreshed record.
  2. Add `get_active_world_selection(project_id: str) -> Optional[Tuple[WorldSelectionRecord, WorldCandidateRecord]]`:
     - Fetches the latest selection for the project joined with its `WorldCandidateRecord`.
     - Returns tuple or None.
