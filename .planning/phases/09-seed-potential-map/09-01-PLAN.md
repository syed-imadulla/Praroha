# Phase 9 Plan 1 (09-01-PLAN.md): Backend Seed Potential Map Service

## Goal
Implement the backend models, repository functions, AI provider extraction methods, and REST endpoints for the Seed Potential Map, accompanied by a comprehensive Pytest suite.

---

## Proposed Changes

### 1. Data Models (`backend/app/models/potential.py`)
- Define `SeedPotentialCategory` (`explicit`, `inferred`, `open`).
- Define `PotentialItemStatus` (`pending`, `accepted`, `rejected`).
- Define `SeedPotentialItem` (base Pydantic/SQLModel schema).
- Define `SeedPotentialItemRecord` (SQLModel table with foreign key `project_id -> projects.id`).
- Define `SeedPotentialItemUpdate` and `BatchPotentialStatusUpdate` schemas.
- Export in `backend/app/models/__init__.py`.

### 2. Repository Layer (`backend/app/repositories/project_repo.py`)
- Add `create_potential_items(project_id, items: List[SeedPotentialItem]) -> List[SeedPotentialItemRecord]`.
- Add `get_potential_items(project_id) -> List[SeedPotentialItemRecord]`.
- Add `update_potential_item_status(project_id, item_id, status) -> Optional[SeedPotentialItemRecord]`.
- Add `batch_update_potential_item_statuses(project_id, updates) -> List[SeedPotentialItemRecord]`.

### 3. AI Providers
- `backend/app/providers/base.py`: Add `extract_potential(seed, dna)`.
- `backend/app/providers/mock_provider.py`:
  - Implement deterministic canonical fixture for *"A child discovers a forgotten city beneath the ocean"*.
  - Implement fallback heuristic for arbitrary seeds.
- `backend/app/providers/gemini_provider.py`:
  - Implement Gemini API call with strict structured JSON schema.
  - Graceful fallback to `MockProvider` on timeout/quota/error.

### 4. Router & Endpoints (`backend/app/routers/potential.py`)
- `POST /api/projects/{id}/potential/extract`: Run extraction and store items.
- `GET /api/projects/{id}/potential`: Fetch stored items.
- `PATCH /api/projects/{id}/potential/{item_id}`: Update single item status.
- `POST /api/projects/{id}/potential/batch`: Batch update item statuses.
- Mount router in `backend/app/main.py`.

### 5. Automated Tests (`backend/tests/test_potential.py`)
- Test schema validation for potential items.
- Test MockProvider deterministic extraction for canonical demo seed.
- Test fallback behavior when Gemini API call fails.
- Test repository persistence and CRUD operations.
- Test API endpoints: extract, get, patch, batch update.

---
