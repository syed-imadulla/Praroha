# Phase 9 Plan 2 (09-02-PLAN.md): Frontend Seed Potential Canvas & Interactive Controls

## Goal
Implement the frontend user interface for the Seed Potential Map, allowing creators to inspect explicit, inferred, and open possibilities, and accept or reject inferred directions with instant visual feedback.

---

## Proposed Changes

### 1. Types & Client (`frontend/src/types/index.ts` & `frontend/src/api/client.ts`)
- Add `SeedPotentialCategory`, `PotentialItemStatus`, `SeedPotentialItem`, and update request payloads to `types/index.ts`.
- Add API client methods in `api/client.ts`:
  - `extractPotentialItems(projectId: string)`
  - `getPotentialItems(projectId: string)`
  - `updatePotentialItemStatus(projectId: string, itemId: string, status: string)`
  - `batchUpdatePotentialStatuses(projectId: string, items: { id: string; status: string }[])`

### 2. Workspace Store (`frontend/src/store/workspaceStore.ts`)
- Add `potentialItems: SeedPotentialItem[]` state.
- Add `isExtractingPotential: boolean` state.
- Add actions: `loadPotentialItems`, `generatePotentialItems`, `setPotentialItemStatus`.
- Integrate potential hydration into `loadCanonicalDemoProject`.

### 3. Canvas Component (`frontend/src/components/SeedPotentialCanvas.tsx`)
- Render 3 lanes:
  1. **Explicit Elements**: Cyan border/glow, display evidence snippet, non-editable anchor status.
  2. **AI-Inferred Possibilities**: Indigo/Purple theme, confidence indicator, clear "AI-inferred possibility" badge, Accept (✓) and Reject (✕) toggle buttons, visual dimming on rejection and glowing border on acceptance.
  3. **Open Creative Questions**: Amber theme, curiosity prompt cards.
- Quick action "Proceed to Three Worlds" advancing to Stage 3 with accepted directions clearly highlighted.

### 4. Workspace Integration (`frontend/src/components/WorkspaceCanvas.tsx` / `StageProgressHeader.tsx`)
- Allow access to Seed Potential Map directly after Seed Understanding (Stage 2) or via clean sub-tab / stage toggle without breaking the 7-stage keyboard navigation (`1` through `7`).

### 5. Automated Verification & E2E (`frontend/e2e/test_phase9_potential.cjs`)
- Scenario 1: Canonical demo hydrates Seed Potential items with explicit, inferred, and open items.
- Scenario 2: Clicking Accept marks an inferred possibility as accepted.
- Scenario 3: Clicking Reject marks an inferred possibility as rejected and visually dims the card.
- Scenario 4: User can advance to Three Worlds with accepted preferences preserved.

---

## Verification Criteria
- `npm --prefix frontend run build` completes with zero TypeScript or bundling errors.
- Playwright E2E test passes cleanly.
