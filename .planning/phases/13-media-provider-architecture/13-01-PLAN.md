# Phase 13 Plan 1 (13-01-PLAN.md): Backend Media Provider Engine

## Goal
Implement the decoupled, non-blocking **Media Provider Architecture** (`MED-01`), including discrete modal sub-interfaces (`ImageProvider`, `VoiceProvider`, `VideoProvider`, `AudioProvider`), a deterministic `MockMediaProvider` returning verifiable lightweight assets for offline/CI resilience (`MED-02`), relational `media_assets` database persistence with async job state tracking, an asynchronous `MediaService` with graceful error containment (`MED-03`), and REST API endpoints.

---

## Requirements Addressed
- **MED-01**: Abstract `MediaProvider` base class defining `ImageProvider`, `VoiceProvider`, `VideoProvider`, and `AudioProvider` interfaces.
- **MED-02**: Deterministic `MockMediaProvider` returning verifiable mock media assets for offline/testing resilience.
- **MED-03**: All media generation is strictly asynchronous, non-blocking, and gracefully handled on network/credit failures.

---

## Technical Tasks

### 1. Abstract Media Provider Interfaces (`backend/app/providers/media/base.py`)
- Define `MediaPayload`:
  ```python
  class MediaPayload(BaseModel):
      data: bytes
      mime_type: str
      filename: str
      metadata: Dict[str, Any] = {}
  ```
- Define `ImageProvider(ABC)`:
  - `async def generate_image(self, prompt: str, aspect_ratio: str = "1:1", context: Optional[Dict[str, Any]] = None) -> MediaPayload`
- Define `VoiceProvider(ABC)`:
  - `async def generate_voice(self, text: str, voice_id: str = "default", context: Optional[Dict[str, Any]] = None) -> MediaPayload`
- Define `VideoProvider(ABC)`:
  - `async def generate_video(self, prompt: str, duration_sec: int = 5, context: Optional[Dict[str, Any]] = None) -> MediaPayload`
- Define `AudioProvider(ABC)`:
  - `async def generate_audio(self, prompt: str, mood: str = "ambient", duration_sec: int = 15, context: Optional[Dict[str, Any]] = None) -> MediaPayload`
- Define `MediaProvider(ABC)`:
  - Composite holding properties `image: ImageProvider`, `voice: VoiceProvider`, `video: VideoProvider`, `audio: AudioProvider`.

### 2. Deterministic Mock Media Provider (`backend/app/providers/media/mock.py`)
- Implement `MockImageProvider`:
  - Synthesizes valid, self-contained SVG graphics with styled gradients, entity title watermark, and dark aesthetic.
- Implement `MockVoiceProvider`:
  - Synthesizes valid RIFF WAV audio files (44-byte standard PCM header + generated audio samples), natively playable in HTML5 `<audio>`.
- Implement `MockVideoProvider`:
  - Synthesizes valid lightweight MP4 / animated clip payloads with container headers.
- Implement `MockAudioProvider`:
  - Synthesizes valid ambient RIFF WAV audio loops with mood metadata.
- Implement `MockMediaProvider`:
  - Assembles all mock modality providers with sub-50ms deterministic response times and 100% offline capability.

### 3. Media Provider Factory (`backend/app/providers/media/factory.py`)
- Implement `MediaProviderFactory`:
  - Resolves individual modality providers from application configuration / environment variables (`IMAGE_PROVIDER`, `VOICE_PROVIDER`, `VIDEO_PROVIDER`, `AUDIO_PROVIDER`), defaulting securely to `mock`.

### 4. Data Models & Database Migration (`backend/app/models/media.py` & `project_repo.py`)
- Define schemas in `backend/app/models/media.py`:
  - `MediaType = Literal["image", "voice", "video", "audio"]`
  - `MediaJobStatus = Literal["queued", "processing", "completed", "failed"]`
  - `MediaAssetRecord`, `MediaGenerationRequest`, `MediaJobResponse`, `MediaAssetRead`.
- In `backend/app/repositories/project_repo.py`:
  - Add `media_assets` table creation to `_init_db`:
    ```sql
    CREATE TABLE IF NOT EXISTS media_assets (
        id VARCHAR PRIMARY KEY,
        project_id VARCHAR NOT NULL,
        entity_type VARCHAR NOT NULL,
        entity_id VARCHAR NOT NULL,
        media_type VARCHAR NOT NULL,
        status VARCHAR NOT NULL,
        asset_url TEXT,
        mime_type VARCHAR,
        prompt TEXT NOT NULL,
        provider_name VARCHAR NOT NULL,
        error_message TEXT,
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        completed_at TIMESTAMP,
        FOREIGN KEY(project_id) REFERENCES projects(id) ON DELETE CASCADE
    );
    ```
  - Implement CRUD repository methods: `create_media_asset`, `update_media_asset`, `get_media_asset`, `list_media_assets`.

### 5. Asynchronous Media Service (`backend/app/services/media_service.py`)
- Implement `MediaService`:
  - `dispatch_job(project_id, entity_type, entity_id, media_type, prompt, context)`:
    - Creates asset record in state `queued`.
    - Spawns asynchronous worker task `_execute_job(asset_id)`.
    - Immediately returns initial `MediaJobResponse` (`< 15ms`).
  - `_execute_job(asset_id)`:
    - Transitions status to `processing`.
    - Invokes corresponding modality provider.
    - Saves binary payload using `StorageProvider` (`LocalStorageProvider` or `SupabaseStorageProvider`).
    - Updates status to `completed` with public `asset_url` and `completed_at`.
    - Contains all errors gracefully: catches exceptions, updates status to `failed` with `error_message`, preventing unhandled crashes.

### 6. REST API Endpoints (`backend/app/routers/media.py`)
- `POST /api/projects/{id}/media/generate`: Dispatches async media generation job.
- `GET /api/projects/{id}/media/jobs/{job_id}`: Polls job status and asset URL.
- `GET /api/projects/{id}/media/assets`: Lists media assets with optional filtering by `entity_id` and `media_type`.
- `GET /api/media/providers/health`: Returns health and configuration of all media sub-providers.
- Register router in `backend/app/main.py`.

- Test 3: `MediaProviderFactory` correctly resolves providers per modality.

- Test 5: Graceful error containment (`status = 'failed'` with `error_message` on simulated failure).
