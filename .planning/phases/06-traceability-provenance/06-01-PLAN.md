<name>Task 2: Dynamic DAG Synthesis & Causal Explanation Service</name>
<files>backend/app/services/lineage_service.py</files>
<read_first>backend/app/repositories/project_repo.py, backend/app/models/lineage.py</read_first>

  1. Create `backend/app/services/lineage_service.py`:
     - Class `LineageService`:
       - `__init__(self, repo: ProjectRepository)`
       - `async def build_project_lineage(self, project_id: str) -> TraceGraphRead`:
         1. Fetch `project = await self.repo.get_project(project_id)`. If missing, raise KeyError.
         2. Build `node-seed`:
            - `id`: `"node-seed"`
            - `entity_type`: `"root_seed"`
            - `label`: `"Root Idea Seed"`
            - `title`: `"Original Creative Premise"`
            - `summary`: `project.seed_text`
            - `causal_explanation`: `"The immutable root inspiration and starting anchor for all downstream worldbuilding."`
            - `stage`: 1
         3. Fetch `seed_dna = await self.repo.get_seed_dna(project_id)`:
            - If present, build `node-dna`:
              - `id`: `"node-dna"`
              - `entity_type`: `"seed_dna"`
              - `label`: `"Distilled Seed DNA"`
              - `title`: `seed_dna.dna.premise`
              - `summary`: `f"Tone: {seed_dna.dna.tone} • Themes: {', '.join(seed_dna.dna.themes[:3])}"`
              - `causal_explanation`: `f"Extracted to ground universe generation in core narrative themes ({', '.join(seed_dna.dna.themes[:2])}) and boundary constraints ({', '.join(seed_dna.dna.constraints[:2])})."`
              - `parent_ids`: `["node-seed"]`
              - `stage`: 2
            - Add edge `edge-seed-dna` (`derived_from`, `"Understands Intent"`).
         4. Fetch `worlds = await self.repo.get_world_candidates(project_id)`:
            - For each candidate `w`:
              - Add `node-world-{w.id}`:
                - `entity_type`: `"world_candidate"`
                - `label`: `f"Candidate 0{w.candidate_index}: {w.title}"`
                - `title`: `w.title`
                - `summary`: `w.concept`
                - `causal_explanation`: `f"Formulated as an exploration of the {w.archetype} archetype with aesthetic '{w.aesthetic}', testing core tension '{w.core_tension}'."`
                - `parent_ids`: `["node-dna"]`
                - `stage`: 3
              - Add edge `edge-dna-world-{w.id}` (`derived_from`, `"Explores Archetype"`).
         5. Fetch `selection_tuple = await self.repo.get_active_world_selection(project_id)`:
            - If present (`selection, chosen_world`):
              - Add `node-selection`:
                - `entity_type`: `"human_selection"`
                - `label`: `f"Selected: {chosen_world.title}"`
                - `title`: `f"Creative Commitment: {chosen_world.title}"`
                - `summary`: `selection.user_rationale or "Confirmed creative direction without additional rationale."`
                - `causal_explanation`: `f"Human creator locked {chosen_world.title} ({chosen_world.archetype}) as the canonical direction for universe expansion. Rationale: '{selection.user_rationale or 'Direct creator commitment'}."`
                - `parent_ids`: `[f"node-world-{chosen_world.id}"]`
                - `stage`: 4
              - Add edge `edge-world-selection` (`selected_by`, `"Human Choice Gate"`).
         6. Fetch `unfolded = await self.repo.get_unfolded_universe(project_id)`:
            - If present:
              - **World Bible Node**:
                - Add `node-bible`:
                  - `entity_type`: `"world_bible"`
                  - `label`: `"World Bible & Laws"`
                  - `title`: `f"Canon Laws of {chosen_world.title}"`
                  - `summary`: `unfolded.world_bible.physics_rules[:140]`
                  - `causal_explanation`: `f"Constructed to define physical laws, geography, and factions governing {chosen_world.title}, strictly abiding by Seed DNA constraints."`
                  - `parent_ids`: `["node-selection"]`
                  - `stage`: 5
                - Add edge `edge-selection-bible` (`generated_for`, `"Establishes Canon"`).
              - **Key Locations**:
                - For each `loc` (index `i`):
                  - Add `node-loc-{i}`:
                    - `id`: `f"node-loc-{i}"`
                    - `entity_id`: `f"loc-{i}"`
                    - `entity_type`: `"key_location"`
                    - `label`: `loc.name`
                    - `title`: `loc.name`
                    - `summary`: `loc.description`
                    - `causal_explanation`: `f"Formed as a landmark environment for {chosen_world.title}: {loc.description}"`
                    - `parent_ids`: `["node-bible"]`
                    - `stage`: 5
                    - `metadata`: `{"location_index": i, "location_name": loc.name}`
                  - Add edge `edge-bible-loc-{i}` (`appears_in`, `"Anchored in Canon"`).
              - **Characters**:
                - For each `c` in `unfolded.characters`:
                  - Add `node-char-{c.id}`:
                    - `entity_type`: `"character"`
                    - `label`: `f"{c.name} ({c.role})"`
                    - `title`: `c.name`
                    - `summary`: `f"Motivation: {c.motivation} • Conflict: {c.core_conflict}"`
                    - `causal_explanation`: `f"Cast as {c.role} ({c.archetype}) in {chosen_world.title} to embody the narrative conflict between '{c.motivation}' and '{c.core_conflict}' under canon rules."`
                    - `parent_ids`: `["node-bible"]`
                    - `stage`: 5
                  - Add edge `edge-bible-char-{c.id}` (`constrained_by`, `"Inhabits Canon"`).
              - **Relationships**:
                - Create character name lookup dictionary from loaded characters: `char_map = {c.id: c.name for c in unfolded.characters}`.
                - (Do not assume `CharacterRelationshipRecord` has `source_character_name` or `target_character_name` fields).
                - For each `r` in `unfolded.relationships`:
                  - `src_name = char_map.get(r.source_character_id, "Character A")`
                  - `tgt_name = char_map.get(r.target_character_id, "Character B")`
                  - Add `node-rel-{r.id}`:
                    - `entity_type`: `"relationship"`
                    - `label`: `f"{src_name} ↔ {tgt_name}"`
                    - `title`: `r.relation_type`
                    - `summary`: `r.dynamic_description`
                    - `causal_explanation`: `f"Interpersonal dynamic connecting {src_name} and {tgt_name} ({r.relation_type}): {r.dynamic_description}"`
                    - `parent_ids`: `[f"node-char-{r.source_character_id}", f"node-char-{r.target_character_id}"]`
                    - `stage`: 5
                  - Add edge from source character to relationship (`appears_in`, `"Participant"`).
                  - Add edge from target character to relationship (`appears_in`, `"Participant"`).
              - **Scenes**:
                - For each `s` in `unfolded.scenes`:
                  - Add `node-scene-{s.id}`:
                    - `entity_type`: `"scene"`
                    - `label`: `f"Scene {s.scene_number}: {s.title}"`
                    - `title`: `s.title`
                    - `summary`: `f"Dramatic Q: {s.dramatic_question}"`
                    - `causal_explanation`: `f"Dramatic encounter staged at {s.location_setting} to test '{s.dramatic_question}' leading to pivotal outcome '{s.pivotal_outcome}'."`
                    - `parent_ids`: `["node-bible"]`
                    - `stage`: 5
                  - Add edge `edge-bible-scene-{s.id}` (`appears_in`, `"Enacts World Canon"`).
         7. Return `TraceGraphRead(project_id=project_id, root_node_id="node-seed", nodes=nodes, edges=edges)`.
       - `async def get_node_ancestors(self, project_id: str, node_id: str) -> AncestorPathRead`:
         1. Call `build_project_lineage(project_id)`.
         2. Map node index by ID and parents by node.
         3. Traverse backwards from `node_id` through all transitive `parent_ids` until `node-seed`.
         4. Collect ancestor nodes, connecting edges, and synthesize a chronological summary explanation.
         5. Return `AncestorPathRead`.
</action>
