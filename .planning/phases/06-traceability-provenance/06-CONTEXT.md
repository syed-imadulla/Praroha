# Phase 6 Context: Traceability & Provenance (TRAC-01 to TRAC-03)

## Phase Purpose
Phase 6 builds the **Traceability & Provenance Engine (Tattva 5: Sambandha)**. It connects every entity generated in the universe (World Bible, Key Locations, Characters, Dynamics, Story Scenes) back through Human Selection, World Candidates, and Seed DNA to the immutable Root Seed via an interactive Directed Acyclic Graph (DAG) with plain-language causal explanations.

---

## Locked Decisions

### D-01: Relational Dynamic Synthesis (Backend)
- The Traceability DAG is dynamically synthesized on demand from relational database records (`ProjectRecord`, `SeedDNARecord`, `WorldCandidateRecord`, `WorldSelectionRecord`, `WorldBibleRecord`, `CharacterRecord`, `CharacterRelationshipRecord`, `SceneRecord`).
- **Endpoint**: `GET /api/projects/{project_id}/lineage`
- **Response Format**:
  - `nodes`: List of `TraceNode`:
    - `id`: Unique node ID (e.g. `node-seed`, `node-dna`, `node-world-{id}`, `node-char-{id}`, `node-scene-{id}`, `node-loc-{index}`)
    - `entity_id`: Underlying record UUID / ID (or deterministic ID `loc-{index}` for key locations)
    - `entity_type`: `root_seed` | `seed_dna` | `world_candidate` | `human_selection` | `world_bible` | `key_location` | `character` | `relationship` | `scene`
    - `label`: Short title / name
    - `stage`: Stage identifier (1 to 5)
    - `summary`: Short summary or quote
    - `causal_explanation`: Plain-language explanation answering "Why does this exist?"
    - `parent_ids`: List of direct ancestor node IDs
    - `metadata`: Dictionary containing entity-specific details (e.g., `location_index`, `location_name` for locations)
  - `edges`: List of `TraceEdge`:
    - `id`: Edge ID
    - `source`: Source node ID (parent)
    - `target`: Target node ID (child)
    - `relation_type`: `derived_from` | `selected_by` | `constrained_by` | `appears_in` | `generated_for`
    - `label`: Human-readable edge label (e.g. "Human Gate Committed", "Constrained by Tone", "Features Inhabitant")
  - `root_node_id`: ID of the Root Seed node

### D-02: Deterministic Causal Explanation Engine (TRAC-03)
- Plain-language explanations are generated by a deterministic synthesis module that links:
  - Root seed premise & intent
  - Seed DNA constraints, tone, and themes
  - Chosen world candidate archetype and title
  - Creator selection rationale
  - Entity-specific attributes (character conflict, scene outcome, location description)
- **Relationship Name Resolution**: Do not assume `CharacterRelationshipRecord` has `source_character_name` or `target_character_name` fields. Resolve `source_character_id` and `target_character_id` against the loaded `characters` list to get character names for node labels and causal explanations.
- **Zero raw chain-of-thought tokens** or prompt strings are ever exposed in nodes.
- Explanations read naturally (e.g., *"Dr. Althea Thorne was generated for the Bio-City direction because the creator committed to exploring symbiotic biology under deep water pressure, requiring a lead researcher whose internal conflict tests the Seed DNA boundary of human intrusion vs. ecological balance."*).

### D-03: Stage 6 Hybrid Canvas UX
- **Canvas Component**: `frontend/src/components/TraceabilityCanvas.tsx` mounted at `activeStage === 'trace'`.
- Layout:
  1. **Pipeline Stage Lanes / Node-Edge Graph**:
     - Visual column or layered DAG layout:
       - Lane 1: **Root Seed** (Immutable origin)
       - Lane 2: **Seed DNA** (Distilled Intent & Constraints)
       - Lane 3: **World Candidates & Human Selection** (Latent options + Committed human choice)
       - Lane 4: **World Codex & Locations** (Physics, geography, key landmarks)
       - Lane 5: **Inhabitants & Dynamics** (Characters & relationships)
       - Lane 6: **Story Beats / Scenes** (Narrative drama)
  2. **Active Path Glow & Dimming**:
     - Clicking any node marks it as active.
     - Computes all transitive ancestors back to `node-seed`.
     - Glows selected node and all ancestor nodes/edges with cyan/amber/emerald highlights.
     - Dims all non-ancestor nodes to `opacity-35`.
  3. **Interactive Causal Inspector Card**:
     - Anchored card displaying the selected node's title, entity type chip, parent links, and full "Why does this exist?" causal explanation.
     - Button: "Trace Back to Root" to animate the trail.

### D-04: Cross-Stage Deep Linking
- Add a `"Trace Lineage"` icon button on all cards in Stage 5 Codex (`UniverseCodexCanvas.tsx`):
  - **Key Locations**: Resolve to deterministic lineage node ID `node-loc-{index}` using the location index (or `metadata.location_index`). Do not invent a location UUID.
  - Character Cards: `jumpToTraceNode("node-char-" + char.id)`
  - Relationship Cards: `jumpToTraceNode("node-rel-" + rel.id)`
  - Story Scene Cards: `jumpToTraceNode("node-scene-" + scene.id)`
- Clicking `"Trace Lineage"` switches `activeStage` to `'trace'`, sets `selectedNodeId` in the workspace store, and focuses that entity in the graph.

## Technical Constraints & Boundaries
1. No external graph databases (Neo4j, Memgraph).
2. Traversal is clean Python/TypeScript logic (DAG is small, ~15-25 nodes total for a project).
3. Stage 6 unlocks when project status is `universe_unfolded`.
4. Automated verification via backend Pytest and Playwright E2E browser tests.
