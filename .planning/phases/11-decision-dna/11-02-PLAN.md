# Phase 11 Plan 2 (11-02-PLAN.md): Frontend Decision DNA UI & E2E Verification

## Goal
Implement interactive Stage 4 Decision DNA capture (creative priorities chips, inferred exclusions checklist, custom negative guardrails, rationale, directives), Stage 5 persistent Decision DNA Anchor Pill Bar in the Universe Codex, Inspector Lineage integration, and automated Playwright E2E verification.

---

## Requirements Addressed
- **DDNA-01**: Interactive UI controls for capturing creative priorities, rejected directions, rationale, and custom directives during Stage 4.
- **DDNA-02**: Store and API client methods transmitting the complete Decision DNA payload upon confirmation.
- **DDNA-03**: Persistent Decision DNA summary strip / pill bar in Stage 5 Codex UI showing archetype, priorities, and exclusions, preserving causal visibility from choice to universe.

---

## Proposed Changes

### 1. Types (`frontend/src/types/index.ts`)
- Define `DecisionDNA` interface:
  ```typescript
  export interface DecisionDNA {
    selected_world_id: string;
    selected_title: string;
    selected_archetype: string;
    user_rationale?: string | null;
    creative_priorities: string[];
    rejected_directions: string[];
    custom_directives?: string | null;
    created_at: string;
  }
  ```
- Define `WorldSelectionCreate` interface:
  ```typescript
  export interface WorldSelectionCreate {
    user_rationale?: string | null;
    creative_priorities?: string[];
    rejected_directions?: string[];
    custom_directives?: string | null;
  }
  ```
- Extend `WorldSelectionRead` with `decision_dna?: DecisionDNA`.

### 2. API Client & Workspace Store
- `frontend/src/api/client.ts`:
  - Update `selectWorld(projectId, candidateId, payload?: WorldSelectionCreate | string)`:
    - Normalizes string argument into `{ user_rationale: string }` for backward compatibility.
    - Sends full JSON object when `WorldSelectionCreate` is provided.
- `frontend/src/store/workspaceStore.ts`:
  - Update `confirmWorldSelection`:
    ```typescript
    confirmWorldSelection: (
      candidateId: string,
      payload?: WorldSelectionCreate | string
    ) => Promise<boolean>;
    ```
  - Store returned `activeSelection` with `decision_dna` in workspace state.

### 3. Stage 4: World Selection Canvas (`frontend/src/components/WorldSelectionCanvas.tsx`)
In the chosen candidate confirmation panel:
1. **Creative Priorities Section**:
   - Preset priority chips:
     - `Atmospheric Lore Depth`
     - `Character-Driven Conflict`
     - `Ecological / Symbiotic Mystery`
     - `Philosophical & Ethical Stakes`
     - `Visceral Sensory Worldbuilding`
     - `Intimate Personal Scale`
   - Toggle selection state with visual cyan glow.
   - Custom priority tag input (+ Add button or Enter key).
2. **Rejected Directions & Creative Guardrails Section**:
   - Inferred negative guardrails from the two unselected candidate worlds:
     - For Candidate 1 (Lost Civilization): `"Sunken classical ruins & relic looting tropes"`
     - For Candidate 3 (Time Capsule): `"Cold War militarized bunker paranoia"`
   - Checkboxes allowing the creator to toggle each inferred exclusion on/off.
   - Custom negative guardrails input (e.g. `"No magical teleportation"`).
3. **Creator Rationale Textarea**:
   - Freeform rationale for choosing this direction over others.
4. **Custom Creative Directives Input**:
   - Non-negotiable instructions for subsequent generation.
5. **Confirmation Action**:
   - Compiles state into `WorldSelectionCreate` and calls `confirmWorldSelection(selectedWorldId, payload)`.

### 4. Stage 5: Universe Codex Canvas (`frontend/src/components/UniverseCodexCanvas.tsx`)
- Add **Decision DNA Anchor Strip / Pill Bar** directly under the codex header:
  - Selected Archetype pill (e.g., `Bio-City • Radical (Symbiotic / Ecological)`).
  - Priority Pills with cyan accents (e.g., `★ Ecological / Symbiotic Mystery`, `★ Atmospheric Lore Depth`).
  - Active Exclusions / Guardrails with amber/rose accent (e.g., `⊘ No sunken ruins archaeology`, `⊘ No Cold War bunker tech`).
  - "Inspect Full DNA" action opening the Inspector Drawer directly to the Lineage tab.
  - Preserves causal visibility: creator immediately sees how their Stage 4 choices anchor Stage 5.

### 5. Inspector Drawer (`frontend/src/components/InspectorDrawer.tsx`)
- Enhance the Step 3 node in the Lineage tab:
  - If `activeSelection?.decision_dna` is present:
    - Display selected archetype.
    - Display creator rationale.
    - Display creative priorities tag list.
    - Display active negative guardrails tag list.
    - Display custom directives if provided.

### 6. Automated E2E Verification (`frontend/e2e/test_phase11_decision_dna.cjs`)
Playwright script verifying:
1. **Scenario 1**: Stage 4 Decision DNA capture — selecting priority chips, toggling inferred exclusions, typing custom negative guardrail and directive.
2. **Scenario 2**: Confirmation lock sends complete Decision DNA payload, verified via `/api/projects/{id}/selection`.
3. **Scenario 3**: Stage 5 persistent Decision DNA Anchor Pill Bar renders chosen archetype, priorities, and exclusions.
4. **Scenario 4**: Lineage Inspector Drawer renders Step 3 Decision DNA node with priorities, exclusions, and rationale.
5. **Scenario 5**: Verification of canonical Bio-City demo: pre-populated Decision DNA loads instantly without UI error.
