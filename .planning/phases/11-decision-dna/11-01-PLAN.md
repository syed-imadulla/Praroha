# Phase 11 Plan 1 (11-01-PLAN.md): Backend Decision DNA Engine

## Goal
Implement relational persistence for **Decision DNA** (`DDNA-01`, `DDNA-02`), automatic database schema migration with backward compatibility, stable snapshot extraction during Stage 5 unfolding, and prompt injection of the immutable `DECISION DNA CREATIVE CONTRACT` into downstream AI providers (`DDNA-03`), validated by a dedicated Pytest suite.

---

## Requirements Addressed
- **DDNA-01**: World selection records comprehensive Decision DNA: selected world ID, title, archetype, creator rationale, creative priorities, rejected directions, custom directives, and timestamp.
- **DDNA-02**: Decision DNA is persisted relationally, backward-compatible with legacy selections, and exposed through selection API endpoints.
- **DDNA-03**: During Stage 5 unfolding, a stable Decision DNA snapshot is passed into AI provider context and formatted as a mandatory `DECISION DNA CREATIVE CONTRACT` (priorities, exclusions, rationale) without chain-of-thought leakage.

---

## Proposed Changes

### 1. Data Models (`backend/app/models/selection.py`)
- Define `DecisionDNA(BaseModel)` schema:
  - `selected_world_id: str`
  - `selected_title: str`
  - `selected_archetype: str`
  - `user_rationale: Optional[str] = None`
  - `creative_priorities: List[str] = Field(default_factory=list)`
  - `rejected_directions: List[str] = Field(default_factory=list)`
  - `custom_directives: Optional[str] = None`
  - `created_at: datetime`
- Extend `WorldSelectionBase` and `WorldSelectionRecord`:
  - `creative_priorities_json: str = Field(default="[]")`
  - `rejected_directions_json: str = Field(default="[]")`
  - `custom_directives: Optional[str] = Field(default=None, nullable=True)`
- Extend `WorldSelectionCreate`:
  - `user_rationale: Optional[str] = None`
  - `creative_priorities: List[str] = Field(default_factory=list)`
  - `rejected_directions: List[str] = Field(default_factory=list)`
  - `custom_directives: Optional[str] = None`
- Add method `to_decision_dna(candidate: WorldCandidateRead) -> DecisionDNA` to `WorldSelectionRecord`:
  - Safely deserializes `creative_priorities_json` and `rejected_directions_json`.
  - Populates defaults for legacy selection records.
- Extend `WorldSelectionRead`:
  - `decision_dna: Optional[DecisionDNA] = None`
  - Update `to_read_schema()` to populate `decision_dna`.

### 2. Repository Layer & Schema Migration (`backend/app/repositories/project_repo.py`)
- In `_migrate_columns`:
  - Inspect columns of table `world_selections`.
  - Add missing columns if needed:
    - `creative_priorities_json TEXT DEFAULT '[]'`
    - `rejected_directions_json TEXT DEFAULT '[]'`
    - `custom_directives TEXT`
- In `save_world_selection`:
  - Accept `creative_priorities: Optional[List[str]] = None`, `rejected_directions: Optional[List[str]] = None`, `custom_directives: Optional[str] = None`.
  - Serialize lists to JSON and persist fields on `WorldSelectionRecord`.
- In `create_canonical_demo_project`:
  - Populate canonical Decision DNA for Bio-City:
    - `creative_priorities`: `["Ecological / Symbiotic Mystery", "Atmospheric Lore Depth", "Ethical Stakes"]`
    - `rejected_directions`: `["Classical sunken ruins archaeology", "Cold War militarized technology"]`
    - `user_rationale`: `"Selected Bio-City (Symbiotic / Ecological) for deep biopunk exploration and rich ecological tension."`
    - `custom_directives`: `"Ensure coral bio-luminescence and symbiotic sentience remain central across all layers."`

### 3. Selection REST Router (`backend/app/routers/selection.py`)
- Update `select_world_candidate` endpoint:
  - Extract `creative_priorities`, `rejected_directions`, and `custom_directives` from `body: Optional[WorldSelectionCreate]`.
  - Pass fields to `repo.save_world_selection()`.
  - Return updated `WorldSelectionRead` including `decision_dna`.

### 4. Unfolding Router & Stable Snapshot Strategy (`backend/app/routers/unfold.py`)
- In `unfold_universe`:
  - Fetch active selection `(sel_rec, cand_rec) = await repo.get_active_world_selection(project_id)`.
  - Construct stable `decision_dna` snapshot:
    `decision_dna_snapshot = sel_rec.to_decision_dna(cand_rec.to_read_schema())`
  - Pass `"decision_dna": decision_dna_snapshot.model_dump()` into `context` object for `provider.unfold_universe(context)`.
  - **Guardrail:** Contract is an immutable snapshot *for that unfolding execution*, while relational records remain editable prior to unfolding and re-snapshotable for future mutation/replay workflows.

### 5. Downstream AI Provider Injection (`backend/app/providers/`)
- `backend/app/providers/gemini_provider.py`:
  - Inject explicit `DECISION DNA CREATIVE CONTRACT` into `user_prompt`:
    - `1. MANDATORY CREATIVE PRIORITIES`: Prioritize [creative priorities].
    - `2. NEGATIVE GUARDRAILS & REJECTED DIRECTIONS`: Strictly avoid [rejected directions].
    - `3. CREATOR RATIONALE & DIRECTIVES`: Rationale: [user rationale], Directives: [custom directives].
  - Update system instructions to strictly adhere to the Creative Contract across World Bible, Characters, Relationships, and Scenes.
  - Zero-leakage guardrail: no chain-of-thought token leakage.
- `backend/app/providers/mock_provider.py`:
  - Support `decision_dna` in `context` across canonical and fallback unfolding.

### 6. Automated Pytest Verification (`backend/tests/test_decision_dna.py`)
- Test suite validating:
  1. `test_decision_dna_model_serialization`: Validates `DecisionDNA` schema and JSON conversion.
  2. `test_world_selection_backward_compatibility`: Validates legacy selection rows without Decision DNA fields load safely with valid defaults.
  3. `test_select_world_with_decision_dna`: End-to-end API test selecting candidate with priorities, exclusions, rationale, directives and verifying relational persistence.
  4. `test_decision_dna_snapshot_propagation_to_unfold`: Mocks AI provider and verifies that `decision_dna` snapshot dictionary is passed into `provider.unfold_universe(context)`.
  5. `test_gemini_prompt_creative_contract_injection`: Verifies prompt formatting includes the mandatory `DECISION DNA CREATIVE CONTRACT` structure.
  6. `test_canonical_demo_decision_dna`: Verifies `create_canonical_demo_project()` seeds canonical Decision DNA for Bio-City.
