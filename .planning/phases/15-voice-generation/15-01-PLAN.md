# Phase 15 Plan 1 (15-01-PLAN.md): Backend Voice Provider Engine

## Goal
Implement the concrete **Voice Generation Provider Engine** (`VOX-01`, `VOX-02`), including `EdgeTTSProvider` (primary keyless cloud neural speech generator with transient retry and exponential backoff), `KokoroVoiceProvider` (local inference fallback), a 3-tier fallback orchestrator (`EdgeTTS` $\rightarrow$ `Kokoro` $\rightarrow$ `Mock`), curated voice persona mapping, narrative script derivation for characters and scenes, persistent audio metadata tracking (`voice_id`, `persona`, `duration_sec`, `resolved_provider`), and a comprehensive Pytest test suite with explicit multi-tier fallback and retry-exhaustion verification.

---

## Requirements Addressed
- **VOX-01**: Concrete `EdgeTTSProvider` as primary voice generator for narrative voiceovers without external API keys, with optional local Kokoro-82M fallback and `MockMediaProvider` fallback of last resort.
- **VOX-02**: Backend audio endpoints support voice selection, narration generation, and audio asset persistence.

---

## Technical Tasks

### 1. Dependencies & Package Configuration (`backend/requirements.txt`)
- Add `edge-tts>=7.0.0` to `backend/requirements.txt`.
- Verify environment imports `edge_tts` cleanly.

### 2. Concrete Edge-TTS Voice Provider (`backend/app/providers/media/edge_tts.py`)
- Implement `EdgeTTSProvider(VoiceProvider)`:
  - Curated Voice Persona Mapping:
    - `narrator-deep`: `en-US-ChristopherNeural`
    - `protagonist-resolute`: `en-US-GuyNeural`
    - `inquiring-youth`: `en-US-JennyNeural`
    - `mentor-sage`: `en-GB-RyanNeural`
    - `calm-mystic`: `en-GB-SoniaNeural`
    - `brooding-antagonist`: `en-US-EricNeural`
    - Supports direct voice name input as well (e.g., `en-US-ChristopherNeural`).
  - Synthesis execution:
    - Uses `edge_tts.Communicate(text, voice=resolved_voice)`.
    - Asynchronously gathers audio chunks into binary MP3 bytes (`audio/mpeg`).
  - Resilient Network Handling:
    - Configurable timeout (default 20.0s, via `EDGETTS_TIMEOUT_SEC`).
    - Retries transient network connection/WebSocket errors with exponential backoff (e.g. 1.0s, 2.0s, max 2 retries).
    - Only after retry exhaustion does it raise `ProviderUnavailableError` to allow cascade to the next tier.
  - On success:
    - Returns `MediaPayload(data=audio_bytes, mime_type="audio/mpeg", filename=..., metadata={"voice_id": resolved_voice, "persona": persona, "resolved_provider": "edge-tts", "duration_sec": estimated_duration})`.
  - Implements `health_check()`.

### 3. Local Kokoro-82M Voice Provider (`backend/app/providers/media/kokoro.py`)
- Implement `KokoroVoiceProvider(VoiceProvider)`:
  - Checks if `KOKORO_ENDPOINT` environment variable is configured (e.g. local Kokoro-82M speech microservice).
  - If unset or unreachable, raises `ProviderUnavailableError` allowing immediate cascade to Tier 3 mock.
  - If configured and reachable, dispatches HTTP POST request with text and voice ID.
  - On success:
    - Returns `MediaPayload(data=..., mime_type="audio/wav" or "audio/mpeg", filename=..., metadata={"voice_id": voice_id, "persona": persona, "resolved_provider": "kokoro", "duration_sec": estimated_duration})`.
  - Implements `health_check()`.

### 4. 3-Tier Composite Voice Provider (`backend/app/providers/media/composite_voice.py`)
- Implement `CompositeVoiceProvider(VoiceProvider)`:
  - Encapsulates:
    - Tier 1: `EdgeTTSProvider`
    - Tier 2: `KokoroVoiceProvider`
    - Tier 3: `MockVoiceProvider` (guaranteed safe final fallback)
  - Explicit Fallback Hierarchy:
    1. Edge TTS fails $\rightarrow$ Kokoro succeeds $\rightarrow$ `resolved_provider = "kokoro"` (no unhandled 500 error).
    2. Edge TTS fails $\rightarrow$ Kokoro fails $\rightarrow$ Mock succeeds $\rightarrow$ `resolved_provider = "mock"` (no unhandled 500 error).
  - Error containment:
    - Client never receives an unhandled 500 error for voice generation failure; Mock is guaranteed final fallback.
    - Guarantees consistent payload metadata across all tiers: `voice_id`, `persona`, `resolved_provider`, and `duration_sec`.
  - Implements composite `health_check()`.

### 5. Mock Voice Provider Update (`backend/app/providers/media/mock.py`)
- Update `MockVoiceProvider`:
  - Returns consistent metadata payload: `voice_id`, `persona`, `resolved_provider = "mock"`, and `duration_sec`.
  - Guarantees the frontend persona badge remains meaningful and accurate even under offline mock fallback.

### 6. Media Factory Configuration (`backend/app/providers/media/factory.py`)
- Update `MediaProviderFactory.get_voice_provider()`:
  - Resolves `CompositeVoiceProvider` by default when `VOICE_PROVIDER` is unset or set to `edge_tts`.
  - Resolves `MockVoiceProvider` when `VOICE_PROVIDER=mock`.
- Export new providers in `backend/app/providers/media/__init__.py`.

### 7. Deterministic Spoken Script Derivation & Metadata Persistence (`backend/app/services/media_service.py`)
- In `MediaService._run_generation_pipeline`:
  - When `request.media_type == "voice"`:
    - **Deterministic Script Derivation Rule**:
      - If creator explicitly supplies spoken text in the generation request, **preserve it exactly**. Never silently rewrite or mutate creator-provided text.
      - If spoken text is not explicitly supplied (or is empty), derive the canonical spoken script from entity fields using deterministic templates:
        - For Characters: `"I am {name}, {role}. My motivation: {motivation}. My core conflict: {core_conflict}."`
        - For Scenes: `"Scene {scene_number}: {title}. In {location_setting}. {conflict_narrative}. Outcome: {pivotal_outcome}."`
    - Passes resolved text and `voice_id` (or persona slug) to provider.
    - Persists audio record with `metadata_json` storing consistent fields: `voice_id`, `persona`, `duration_sec`, and `resolved_provider`.

### 8. Pytest Verification Suite (`backend/tests/test_voice_generation.py`)
- Implement comprehensive test suite:
  1. `test_edgetts_voice_persona_mapping`: Validates all 6 personas resolve to appropriate neural voices.
  2. `test_edgetts_retry_and_backoff_recovery`: Simulates transient network failure and verifies retry succeeds.
  3. `test_edgetts_retry_exhaustion_cascades_to_fallback`: Simulates persistent network failure and verifies cascade occurs only after retry exhaustion.
  4. `test_3_tier_fallback_edgetts_fail_kokoro_success`: Explicitly verifies Edge TTS fails $\rightarrow$ Kokoro succeeds $\rightarrow$ asserts `resolved_provider == "kokoro"`, no unhandled 500 error, and consistent metadata (`voice_id`, `persona`, `duration_sec`).
  5. `test_3_tier_fallback_edgetts_and_kokoro_fail_mock_success`: Explicitly verifies Edge TTS fails $\rightarrow$ Kokoro fails $\rightarrow$ Mock succeeds $\rightarrow$ asserts `resolved_provider == "mock"`, valid WAV binary, zero 500 errors, and consistent metadata (`voice_id`, `persona`, `duration_sec`).
  6. `test_deterministic_spoken_script_derivation`: Asserts creator-supplied text is preserved exactly without rewriting, and canonical templates are used deterministically when empty.
  7. `test_voice_metadata_persistence`: Verifies database record preserves `voice_id`, `persona`, `duration_sec`, `resolved_provider`, `metadata_json`, `prompt`, `asset_url`.
  8. `test_voice_api_endpoint_with_persona`: Verifies REST API invocation with `voice_id`.
  9. Full regression run: verifies all 94 existing tests continue to pass.
