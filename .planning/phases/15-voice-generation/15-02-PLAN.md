# Phase 15 Plan 2 (15-02-PLAN.md): Frontend Voice Generation Experience & Custom Narrative Audio Player

## Goal
Implement the frontend voice generation and playback experience (`VOX-03`), including a curated voice persona selector dropdown (`EntityMediaSection.tsx`), multi-entity voice generation coverage across Characters and Scenes / Story Beats (`UniverseCodexCanvas.tsx`), a rich interactive **Custom Narrative Audio Player** (`MediaPreviewCard.tsx`) with play/pause, scrubbable progress bar, time tracking, persona badge, and download action, verified by a comprehensive Playwright E2E test suite.

---

## Requirements Addressed
- **VOX-02**: Backend audio endpoints support voice selection, narration generation, and audio asset persistence.
- **VOX-03**: Frontend provides interactive narration player with play/pause and regenerate controls.

---

## Technical Tasks

### 1. Voice Persona Models & Catalog (`frontend/src/types/index.ts`)
- Define `VoicePersona` interface:
  - `id: string` (e.g. `narrator-deep`)
  - `name: string` (e.g. `Deep Cinematic Narrator`)
  - `voice: string` (e.g. `en-US-ChristopherNeural`)
  - `description: string` (e.g. `Deep, steady, authoritative tone`)
  - `recommendedFor: string` (e.g. `Scenes & World Lore`)
- Export `CURATED_VOICE_PERSONAS: VoicePersona[]` containing the 6 locked archetypes:
  1. `narrator-deep` (`en-US-ChristopherNeural`)
  2. `protagonist-resolute` (`en-US-GuyNeural`)
  3. `inquiring-youth` (`en-US-JennyNeural`)
  4. `mentor-sage` (`en-GB-RyanNeural`)
  5. `calm-mystic` (`en-GB-SoniaNeural`)
  6. `brooding-antagonist` (`en-US-EricNeural`)

### 2. Voice Persona Selector Controls (`frontend/src/components/EntityMediaSection.tsx`)
- In `EntityMediaSection.tsx`:
  - When `availableModalities.includes('voice')`, render a compact voice persona dropdown selector (`data-testid={`voice-persona-selector-${entityId}`}`).
  - Pre-selects recommended persona:
    - For Characters: Auto-suggest based on character role/archetype (e.g. Mentors $\rightarrow$ `mentor-sage`, Protagonists $\rightarrow$ `protagonist-resolute`, Mystics $\rightarrow$ `calm-mystic`).
    - For Scenes: Default to `narrator-deep`.
  - Creator can override persona via dropdown before clicking generate.
  - Dispatches `voice_id` in `generateMediaAction` payload.

### 3. Dual-Target Voice Generation Coverage (`frontend/src/components/UniverseCodexCanvas.tsx`)
- **Characters Tab (Codex Tab 2)**:
  - Ensure Character cards offer Voice generation alongside Portraits with persona selector.
- **Scenes / Story Beats Tab (Codex Tab 3)**:
  - Add `'voice'` to `availableModalities={['image', 'voice', 'audio', 'video']}` in Scene cards.
  - Allows creators to generate dramatic narrative voiceover for each pivotal scene beat.

### 4. Custom Narrative Audio Player (`frontend/src/components/MediaPreviewCard.tsx`)
- Replaces raw HTML `<audio>` tag with an interactive, beautifully styled audio player card:
  - **Play / Pause Toggle Button**:
    - `data-testid="media-voice-play-pause-btn"`
    - Immediate visual toggle between Play and Pause icons.
  - **Interactive Progress Bar / Wave Indicator & Seek Control**:
    - `data-testid="media-voice-progress"`
    - Visual timeline slider reflecting playback progress with interactive scrubbing/seek capability on click or drag (allowing seeking across the audio track, e.g. jumping to approximately 50%).
  - **Time Tracker Display**:
    - `data-testid="media-voice-time"`
    - Formats elapsed time and total duration (`0:04 / 0:18`).
  - **Voice Persona Badge**:
    - `data-testid="media-voice-persona-badge"`
    - Displays consistent metadata (`persona`, `resolved_provider`, `voice_id`, `duration_sec`) so the badge remains meaningful and accurate regardless of which provider succeeds (e.g. `Narrator Deep • edge-tts • en-US-ChristopherNeural`, `Narrator Deep • kokoro • am_adam`, or `Narrator Deep • mock • mock-voice`).
  - **Audio Download Action**:
    - `data-testid="media-voice-download-btn"`
    - Direct download action for the synthesized MP3/WAV audio binary.
  - **Script Inspector & Copy Action**:
    - Spoken text snippet display with 1-click clipboard copy (preserving creator-supplied text exactly, or canonical derived script).

### 5. Frontend Build Validation
- Run `npm run build --prefix frontend` to ensure strict TypeScript compilation and production bundle generation with zero warnings or errors.

### 6. Automated Playwright E2E Test Suite (`frontend/e2e/test_phase15_voice_generation.cjs`)
- Implement comprehensive E2E test suite explicitly verifying generation controls and audio player across locked entity types:
  1. **Scenario 1: Character Voice Monologue Generation & Persona Selection**:
     - Navigates to Codex Characters tab.
     - Verifies voice persona selector exists on Character card.
     - Selects custom persona (e.g., `inquiring-youth` / `en-US-JennyNeural`).
     - Clicks "Generate Voice" and verifies audio asset is synthesized and rendered.
     - Verifies deterministic script derivation preserves creator-provided text or uses canonical character template without silent rewriting.
  2. **Scenario 2: Scene Dramatic Voice Narration in Story Beats Tab**:
     - Navigates to Scenes tab.
     - Verifies voice narration control exists on Scene card.
     - Generates narrative voiceover for the scene using default or chosen persona (`narrator-deep`).
     - Verifies audio asset appears with narrator persona and canonical scene template script.
  3. **Scenario 3: Strengthened Custom Narrative Audio Player & Seek Verification**:
     - Generates or loads synthesized voice asset.
     - Clicks Play button (`data-testid="media-voice-play-pause-btn"`).
     - Verifies current playback time advances (`data-testid="media-voice-time"`).
     - Seeks approximately to 50% using the progress control (`data-testid="media-voice-progress"`).
     - Verifies current playback time changes accordingly to match the seeked position.
     - Clicks Pause button (`data-testid="media-voice-play-pause-btn"`).
     - Verifies playback stops and time stops advancing.
     - Continues verifying persona badge renders consistent metadata (`persona`, `resolved_provider`, `voice_id`) and download action (`data-testid="media-voice-download-btn"`) is functional.
  4. **Scenario 4: Database Persistence & Offline Audio Playback Across Reload**:
     - Reloads page.
     - Navigates back to Characters tab.
     - Verifies previously generated voice asset persists from database and is ready for playback.
  5. **Scenario 5: 3-Tier Fallback Resilience & Accurate Resolved Provider**:
     - Verifies audio generation succeeds under mock/offline mode without breaking the UI or raising unhandled 500 errors.
     - Verifies persona badge displays `resolved_provider = "mock"` and keeps persona identifier meaningful.
  - Capture visual artifact screenshots for all scenarios to the brain directory.

## Verification Criteria
- `npm run build --prefix frontend` succeeds with 0 errors.
- `node frontend/e2e/test_phase15_voice_generation.cjs` passes all 5 scenarios.
- Player seek verification succeeds: Play advances time $\rightarrow$ seek to ~50% updates time $\rightarrow$ Pause stops playback $\rightarrow$ persona badge and download confirmed.
- Consistent persona metadata (`voice_id`, `persona`, `resolved_provider`, `duration_sec`) renders on the frontend badge across all provider tiers.
- Spoken text preserves creator-supplied text exactly, with canonical templates applied deterministically when empty.
- Character monologues and Scene narrations generate successfully.
- All artifact screenshots saved to the brain directory.
