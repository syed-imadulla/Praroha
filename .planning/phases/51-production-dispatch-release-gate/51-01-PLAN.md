# Phase 51: Production Dispatch, UI Enablement & Release Gate Plan

## Phase Goal
Connect the verified on-demand cinematic rendering worker to the PRAROHA web application via non-blocking API dispatch, safely enable the frontend preview generation UI with honest synthetic badges, execute full end-to-end user lifecycle verification, and approve the Milestone 7 release gate.

---

## Architecture Contract & Scope

```mermaid
graph TD
    User([Creator in PWA UI]) -->|Click 'Generate Cinematic Preview'| UI[MediaPreviewCard Component]
    UI -->|POST /api/media/cinematic-preview/jobs| API[FastAPI Web Endpoint]
    API -->|1. Create Job Record| DB[(Supabase PostgreSQL: generation_jobs)]
    API -->|2. Asynchronously Trigger| Trigger[ACA Job Runner]
    API -->|3. Return HTTP 202 Accepted| UI
    UI -->|Poll or Realtime Listen| Status[Job Status: queued -> processing -> completed]
    Trigger -->|Execute Render| Worker[Dedicated Worker Job]
    Worker -->|Update DB & Storage| DB
    Status -->|Completed| VideoPlayer[In-App 720p MP4 Video Player + 'Cinematic Preview' Badge]
```
