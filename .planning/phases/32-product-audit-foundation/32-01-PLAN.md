# Plan 32-01: Product Audit and Production Foundation

## Objective
Perform an exhaustive forensic audit of the entire PRAROHA codebase to benchmark prototype vs production capabilities, catalog gaps in authentication, audio, video, UI, PWA, and deployment configurations, and establish the concrete foundation for sequential Milestone 5 execution.

## Tasks
1. Audit Auth Implementation: Inspect `authStore.ts`, `AuthScreen.tsx`, `routers/auth.py`, and `core/auth.py`. Catalog exact mechanics of the auto-confirm bypass and requirements for true email verification.
2. Audit Audio Generation: Inspect `stable_audio.py`, `ace_step.py`, `composite_audio.py`. Verify API endpoints, credentials in `.env`, timeout handling, and failure modes.
3. Audit Video Generation: Inspect `pyramid_flow.py`, `wan.py`, `composite_video.py`. Verify external endpoint availability, request formats, and storage handling.
4. Audit UI & Front-end Routing: Inspect the 7 stages, modals, navigation, and client state across `frontend/src/components/`.
5. Audit PWA Readiness: Inspect `frontend/package.json`, `frontend/vite.config.ts`, public assets for manifest, icons, and service worker.
6. Audit Deployment & Persistence: Inspect database migrations, Supabase storage, local fallbacks, CORS, and health endpoints.
7. Run and Document Baseline Tests: Execute backend pytest and frontend build, documenting test baseline.

## Verification
- Produce `32-01-SUMMARY.md` documenting evidence-backed findings across all 7 domains.
- Establish clean dependency path for Phases 33–39.
