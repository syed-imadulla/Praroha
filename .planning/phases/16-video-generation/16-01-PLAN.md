# Phase 16 Plan 1 (16-01-PLAN.md): Backend Video Provider Engine

## Goal
Implement the concrete **Video Generation Provider Engine** (`VID-01`, `VID-02`), including `PyramidFlowProvider` (primary cloud/HF inference video generator with 60s timeout), `WanVideoProvider` (local Wan2.1 T2V-1.3B inference fallback), a 3-tier fallback orchestrator `CompositeVideoProvider` (`Pyramid Flow` $\rightarrow$ `Wan2.1` $\rightarrow$ `MockVideoProvider`), cinematic motion prompt enrichment for world teasers and scenes, persistent video technical metadata tracking (`resolved_provider`, `duration_sec`, `aspect_ratio`, `resolution`), and a comprehensive Pytest test suite with explicit multi-tier fallback and zero unhandled 500 errors.

---

## Requirements Addressed
- **VID-01**: Concrete `PyramidFlowProvider` as primary video generator for cinematic scenes, with Wan2.1 T2V-1.3B as practical local fallback, optional/experimental Mochi 1 (not primary due to heavy compute), and `MockMediaProvider` as fallback of last resort.
- **VID-02**: Asynchronous video job polling/generation with graceful fallback to Wan2.1 or mock video clips if resources expire.

---

## Technical Tasks

### 1. Concrete Pyramid Flow Video Provider (`backend/app/providers/media/pyramid_flow.py`)
- Implement `PyramidFlowProvider(VideoProvider)`:
  - Configuration:
    - `PYRAMID_FLOW_ENDPOINT` (or Hugging Face Inference API endpoint).
    - `HF_TOKEN` for optional authorization bearer header.
    - `PYRAMID_FLOW_TIMEOUT_SEC` (default 60.0s).
    - Outage simulation: `context.simulate_pyramid_unavailable` or `PYRAMID_FORCE_UNAVAILABLE=1` raising `ProviderUnavailableError`.
  - Synthesis execution:
    - If unconfigured (no endpoint or token) or simulated unavailable: raises `ProviderUnavailableError`.
    - Dispatches async HTTP POST request using `httpx.AsyncClient` with prompt, duration, resolution, and aspect ratio parameters.
    - Catches `httpx.TimeoutException`, connection errors, and HTTP 4xx/5xx responses; raises `ProviderUnavailableError` without throwing unhandled 500 errors.
  - On success:
    - Returns `MediaPayload(data=mp4_bytes, mime_type="video/mp4", filename=..., metadata={"resolved_provider": "pyramid-flow", "duration_sec": duration_sec, "aspect_ratio": "16:9", "resolution": "720p"})`.
  - Implements `health_check()`.

### 2. Local Wan2.1 T2V-1.3B Video Provider (`backend/app/providers/media/wan.py`)
- Implement `WanVideoProvider(VideoProvider)`:
  - Configuration:
    - `WAN_ENDPOINT` (e.g. `http://localhost:8890/v1/video/generate` for local microservice).
    - `WAN_TIMEOUT_SEC` (default 60.0s).
    - Outage simulation: `context.simulate_wan_unavailable` or `WAN_FORCE_UNAVAILABLE=1` raising `ProviderUnavailableError`.
  - Synthesis execution:
    - If unconfigured or simulated unavailable: raises `ProviderUnavailableError`.
    - Dispatches async HTTP POST request to `WAN_ENDPOINT`.
    - Catches `httpx.TimeoutException` and connection errors; raises `ProviderUnavailableError` to trigger cascade to Tier 3.
  - On success:
    - Returns `MediaPayload(data=mp4_bytes, mime_type="video/mp4", filename=..., metadata={"resolved_provider": "wan2.1", "duration_sec": duration_sec, "aspect_ratio": "16:9", "resolution": "720p"})`.
  - Implements `health_check()`.

### 3. Update Mock Video Provider & Browser Playability (`backend/app/providers/media/mock.py`)
- Update `MockVideoProvider`:
  - Returns deterministic, valid ISO BMFF MP4 binary bytes (`_generate_minimal_mp4_bytes`) with browser-compatible container hierarchy (`ftyp`, `moov`, `mvhd`, `trak`, `mdia`, `minf`, `stbl`, `mdat`).
  - Ensures container boxes include valid timescale and track dimensions so HTML5 `<video>` elements in browsers can parse metadata, report positive duration, set `readyState >= 1`, and play without media decoder errors.
  - Acceptance Rule: "Mock fallback produces a genuinely playable video asset, not merely a file with an .mp4 extension."
  - Returns consistent metadata payload:
    - `resolved_provider`: `"mock"`
    - `duration_sec`: 5
    - `aspect_ratio`: `"16:9"`
    - `resolution`: `"720p"`
    - `mock`: `True`

### 4. Isolated Response Normalization & 3-Tier Composite Video Provider (`backend/app/providers/media/composite_video.py`)
- **Strict Response Isolation**:
  - `PyramidFlowProvider` and `WanVideoProvider` must normalize their vendor-specific HTTP response structures entirely within the provider layer into the unified `MediaPayload(data, mime_type, filename, metadata)` abstraction.
  - Neither `MediaService`, `StorageProvider`, `ProjectRepository`, nor the frontend shall depend on or leak vendor response formats.
- Implement `CompositeVideoProvider(VideoProvider)`:
  - Encapsulates:
    - Tier 1: `PyramidFlowProvider`
    - Tier 2: `WanVideoProvider`
    - Tier 3: `MockVideoProvider` (guaranteed safe final fallback)
  - Explicit Fallback Hierarchy:
    1. Pyramid Flow fails $\rightarrow$ Wan2.1 succeeds $\rightarrow$ `resolved_provider = "wan2.1"` (no unhandled 500 error).
    2. Pyramid Flow fails $\rightarrow$ Wan2.1 fails $\rightarrow$ Mock succeeds $\rightarrow$ `resolved_provider = "mock"` (no unhandled 500 error).
  - Error containment:
    - Client never receives an unhandled 500 error for video generation failure; Mock is guaranteed final fallback.
    - Guarantees consistent payload metadata across all tiers: `resolved_provider`, `duration_sec`, `aspect_ratio`, `resolution`.
  - Implements composite `health_check()`.

### 5. Media Factory Configuration & Exports (`backend/app/providers/media/factory.py`, `__init__.py`)
- Update `MediaProviderFactory.get_video_provider()`:
  - Resolves `CompositeVideoProvider` by default when `VIDEO_PROVIDER` is unset or set to `pyramid_flow` or `composite`.
  - Resolves `MockVideoProvider` when `VIDEO_PROVIDER=mock`.
- Export `PyramidFlowProvider`, `WanVideoProvider`, and `CompositeVideoProvider` in `backend/app/providers/media/__init__.py`.

### 6. Cinematic Prompt Enrichment & Metadata Persistence (`backend/app/services/media_service.py`)
- In `MediaService._run_generation_pipeline`:
  - When `request.media_type == "video"`:
    - **Prompt Preservation & Cinematic Motion Enrichment Rule**:
      - If creator explicitly supplies custom prompt text, **preserve it exactly**. Never silently rewrite or mutate creator-provided text.
      - If prompt is omitted or empty, derive canonical cinematic motion prompt from entity fields:
        - For World (Opening Cinematic Teaser):
          `"{world.title}, {world.concept}. Visual aesthetic: {world.aesthetic}. Cinematic camera panning across the expansive environment, atmospheric fog, photorealistic lighting, 4k cinematic render."`
        - For Scene (Pivotal Story Beat):
          `"Cinematic scene: {scene.title} in {scene.location_setting}. {scene.conflict_narrative}. Slow dramatic camera motion, dynamic environmental movement, atmospheric lighting."`
    - Dispatches to video provider passing enriched prompt, `duration_sec=request.duration_sec or 5`, and context.
    - Persists video record in `media_assets` with `metadata_json` storing consistent technical fields: `resolved_provider`, `duration_sec`, `aspect_ratio`, `resolution`.

### 7. Pytest Verification Suite (`backend/tests/test_video_generation.py`)
- Implement comprehensive test suite:
  1. `test_pyramid_flow_parameters_and_url`: Validates request payload structure, headers, and params.
  2. `test_pyramid_flow_retry_and_timeout`: Validates timeout handling and cascade to Wan2.1.
  3. `test_3_tier_fallback_pyramid_fail_wan_success`: Validates Pyramid Flow failure $\rightarrow$ Wan2.1 success $\rightarrow$ `resolved_provider == "wan2.1"`.
  4. `test_3_tier_fallback_pyramid_and_wan_fail_mock_success`: Validates Pyramid Flow and Wan2.1 failure $\rightarrow$ Mock Video success $\rightarrow$ `resolved_provider == "mock"`, valid MP4 binary, zero 500 errors.
  5. `test_mock_mp4_container_structure`: Verifies MockVideoProvider generates valid binary with proper container boxes (`ftyp`, `moov`, `mvhd`, `mdat`) and browser-compatible structure.
  6. `test_provider_response_isolation`: Verifies `PyramidFlowProvider` and `WanVideoProvider` strictly return normalized `MediaPayload` without leaking vendor-specific payload shapes into service or persistence layers.
  7. `test_cinematic_prompt_enrichment`: Verifies canonical world teaser and scene motion templates and creator text preservation.
  8. `test_video_metadata_persistence`: Generates video and validates database record preserves all metadata (`resolved_provider`, `duration_sec`, `aspect_ratio`, `resolution`).
  9. `test_video_api_endpoints`: Verifies REST API dispatch and job completion.
  10. **Full Regression Across Milestone 2 (Phases 1-15)**:
      - Runs `./.venv/bin/pytest backend/tests/ -v`.
      - Verifies all 103 existing backend tests (including Phase 13, 14, 15 suites) plus all new Phase 16 tests pass with 0 failures.
      - Explicit gate: Do NOT report Phase 16 as complete if existing Phase 13/14/15 functionality regresses.
