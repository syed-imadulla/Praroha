# Phase 16 Plan 2 (16-02-PLAN.md): Frontend Cinematic Video Experience & Lightbox Modal

## Goal
Implement the frontend cinematic video experience (`VID-03`), including the dual "Bring This World to Life" entry points (World Bible Hero CTA banner in Tab 1 and Scene Story Beats in Tab 3 of `UniverseCodexCanvas.tsx`), a rich in-card video player in `MediaPreviewCard.tsx` (play/pause, seek, time tracking, provider badge, download action, and lightbox trigger), an expanding theater modal `VideoLightboxModal.tsx` with technical parameter inspection, and a comprehensive Playwright E2E test suite.

---

## Requirements Addressed
- **VID-03**: Frontend provides "Bring This World to Life" cinematic scene action with embedded video playback.

---

## Technical Tasks

### 1. Interactive Video Lightbox Modal (`frontend/src/components/VideoLightboxModal.tsx`)
- Implement `VideoLightboxModal.tsx` modeled after `ImageLightboxModal.tsx`:
  - Backdrop: Dark translucent background blur (`data-testid="video-lightbox-modal"`).
  - Video Player:
    - Native `<video>` element with controls, `playsInline`, `autoPlay` (`data-testid="lightbox-video-player"`).
    - Centered theater framing maintaining 16:9 aspect ratio.
  - Technical Parameters Inspector:
    - Displays:
      - Resolved Provider badge (`data-testid="lightbox-video-provider"`): e.g. `Pyramid Flow`, `Wan2.1`, or `mock`.
      - Aspect Ratio (`16:9`).
      - Duration (`5s`).
      - Resolution (`720p`).
    - Full prompt inspector with copy action (`data-testid="lightbox-copy-prompt-btn"`).
  - Actions:
    - Download MP4 button (`data-testid="download-video-btn"`).
    - Close button (`data-testid="close-video-lightbox"`) and Escape key dismissal.

### 2. Rich In-Card Video Player (`frontend/src/components/MediaPreviewCard.tsx`)
- Enhance the video preview section in `MediaPreviewCard.tsx`:
  - **Native Video Container**:
    - Wrapped in a responsive container with overlay controls.
    - Video element with `data-testid="media-video-player"`.
  - **Custom Controls Overlay**:
    - **Play / Pause Toggle**:
      - `data-testid="media-video-play-pause-btn"`.
      - Toggle icon between Play and Pause.
    - **Progress & Scrub Control**:
      - `data-testid="media-video-progress"`.
      - Slider tracking elapsed time with interactive seek capability.
    - **Time Tracker Display**:
      - `data-testid="media-video-time"`.
      - Formats elapsed time and total duration (`0:02 / 0:05`).
    - **Technical Provider Badge**:
      - `data-testid="media-video-provider-badge"`.
      - Displays resolved provider and format specs: `Pyramid Flow • 16:9 • 5s`, `Wan2.1 • 16:9 • 5s`, or `mock • 16:9 • 5s`.
    - **Download MP4 Action**:
      - `data-testid="media-video-download-btn"`.
      - Direct download of `.mp4` file.
    - **Expand to Lightbox Trigger**:
      - `data-testid="media-video-lightbox-trigger"`.
      - Opens `VideoLightboxModal`.

### 3. Dual "Bring This World to Life" Entry Points (`frontend/src/components/UniverseCodexCanvas.tsx`)
- **Placement 1: World Bible Hero Banner (Tab 1)**:
  - Add prominent Hero CTA banner: **"Bring This World to Life"** with cinematic film icon (`data-testid="bring-world-to-life-hero-btn"`).
  - Updates `EntityMediaSection` on World Cover to enable `availableModalities={['image', 'video']}` (`data-testid="codex-world-cover-section"`).
  - Allows creators to trigger and preview the opening cinematic teaser video for the active world.
- **Placement 2: Scene Story Beats (Tab 3)**:
  - Ensure Scene cards offer Video generation (`availableModalities={['image', 'voice', 'audio', 'video']}`).
  - Enables creators to generate individual cinematic scene clips for pivotal moments.

### 4. Canonical Motion Prompt Dispatch (`frontend/src/components/EntityMediaSection.tsx`)
- Update `handleGenerate` in `EntityMediaSection.tsx`:
  - When `mediaType === 'video'`, pass `prompt: ''` (or preserve user-supplied prompt if custom input exists) to allow the backend to apply canonical cinematic motion templates (`"{world.title}, {world.concept}..."` or `"Cinematic scene: {scene.title}..."`).
  - Ensures video button displays proper loading state (`data-testid="generate-video-${entityId}"`).

### 5. Frontend Build Validation
- Run `npm run build --prefix frontend` to ensure strict TypeScript compilation and production bundle generation with zero warnings or errors.

### 6. Automated Playwright E2E Test Suite (`frontend/e2e/test_phase16_video_generation.cjs`)
- Implement comprehensive E2E test suite explicitly verifying video generation, controls, and lightbox across locked scenarios:
  1. **Scenario 1: World Teaser Video Generation ("Bring This World to Life" Hero Action)**:
     - Navigates to Codex World Bible tab.
     - Verifies "Bring This World to Life" Hero CTA banner and video generation action.
     - Triggers World teaser generation and verifies video asset is synthesized and rendered.
     - Verifies canonical motion prompt derivation (`"{world.title}, {world.concept}..."`).
  2. **Scenario 2: Scene Story Beat Video Generation**:
     - Navigates to Story Beats / Scenes tab.
     - Verifies Video Clip generation action on Scene card (`data-testid="generate-video-..."`).
     - Triggers scene video generation and verifies synthesized video clip is rendered.
     - Verifies canonical scene motion prompt (`"Cinematic scene: {scene.title}..."`).
  3. **Scenario 3: Video Player Controls & Interactive Lightbox Modal Verification**:
     - Clicks Play button (`data-testid="media-video-play-pause-btn"`).
     - Verifies time advances (`data-testid="media-video-time"`).
     - Seeks using progress control (`data-testid="media-video-progress"`).
     - Clicks Pause button.
     - Clicks Lightbox trigger (`data-testid="media-video-lightbox-trigger"`).
     - Verifies `VideoLightboxModal` opens with backdrop blur, technical metadata (`resolved_provider`, `duration_sec`, `aspect_ratio`), and MP4 download button.
     - Closes modal via Escape or close button (`data-testid="close-video-lightbox"`).
  4. **Scenario 4: Database Persistence & Offline Video Playback Across Reload**:
     - Reloads page.
     - Navigates back to World Bible tab and Scenes tab.
     - Verifies previously generated video assets persist from database and are ready for playback.
  5. **Scenario 5: Strengthened 3-Tier Fallback & Genuine Browser Playability Verification**:
     - Forces Pyramid Flow unavailable via simulated outage / network route failure.
     - Forces Wan2.1 unavailable via simulated outage / network route failure.
     - Triggers video generation and verifies Mock video succeeds without UI crash or unhandled 500.
     - Verifies `resolved_provider === "mock"` and provider badge accurately displays `mock • 16:9 • 5s`.
     - Verifies the rendered `<video>` element loads successfully in browser.
     - Inspects HTMLMediaElement properties:
       - Verifies `video.readyState >= 1` (`HAVE_METADATA` or higher, indicating container header was decoded).
       - Verifies `video.duration > 0` and `!isNaN(video.duration)`.
       - Verifies no video error event occurred (`video.error === null`).
     - **Acceptance Criterion**: *"Mock fallback produces a genuinely playable video asset, not merely a file with an .mp4 extension."*
  - Capture visual artifact screenshots for all scenarios to the brain directory.
