# Phase 29: Secondary UI + Typography + Visibility Polish Plan

## Objective
Execute a comprehensive Senior Product Designer / Frontend Engineer UI polish pass across the PRAROHA application. Establish a consistent, legible typography scale (Cormorant Garamond for titles/headings, Inter for controls/body/metadata with strict minimums: body 15-17px, controls 14-15px, metadata 13px min, labels 12px min, never 9-10px for important info). Eliminate faint low-contrast text (replace `/40` opacity with solid `#5F6D63`, primary `#294B3A`, secondary `#394840`). Polish secondary interface components (modals, drawers, tooltips, lightboxes, tour, shortcuts, media cards, badges, chips, tabs, stage progress) ensuring 44px minimum interactive targets, clear focus/hover states, and comfortable spacing.

## Non-Negotiables
1. **Zero Logic/Backend Changes**: Absolutely no modifications to backend Python code, SQLModel schemas, API endpoints, or database tables.
2. **Preserve All Functional Contracts**: Decision DNA, Human-Only Zones, Origin Ledger, Causal Lineage DAG, Mutation Lab, Counterfactual Replay, and Media Engines remain 100% operational.
3. **Preserve Selectors**: All IDs and data-testids used in tests must remain intact.
4. **Zero Page Horizontal Overflow**: All viewports (1440px, 1024px, 768px, 390px, 360px) must maintain zero page-level horizontal overflow.

## Implementation Waves

### Wave 1: Typography System, Scale & Global Contrast Audit
- Audit and standardize font sizing tokens across typography:
  - Page titles: 32–42px Cormorant Garamond (`font-serif`)
  - Section headings: 22–28px Cormorant Garamond
  - Card headings: 18–22px Cormorant Garamond or semi-bold Inter
  - Body text: 15–17px Inter (`text-base` / `text-[15px]`)
  - Secondary body / controls: 14–15px Inter (`text-sm`)
  - Metadata: 13px Inter (`text-[13px]`), never 9–10px
  - Micro-labels: 12px Inter (`text-xs`), never lower than 12px
- Replace low-contrast faint text classes (`text-[#294B3A]/40`, `text-[#718875]/50`, etc.) with solid, high-contrast `#5F6D63` (muted), `#394840` (secondary), or `#294B3A` (primary).
