# Plan 33-01: Email Authentication and Account Security

## Objective
Implement a production-grade, secure email authentication lifecycle eliminating auto-confirm bypasses. Provide email registration, email confirmation checks, password recovery, session persistence across reloads/restarts, and strict server-side project ownership.

## Tasks
1. Update `authStore.ts`:
   - Implement `resendVerificationEmail(email)`.
   - Implement `sendPasswordResetEmail(email)`.
   - Implement `updatePassword(newPassword)`.
   - Detect `email_confirmed_at` on session user; differentiate between unverified and fully authenticated accounts.
   - Handle hash fragment `#access_token=...&type=recovery` for password reset flows.
2. Upgrade `AuthScreen.tsx`:
   - Support `signin`, `signup`, `forgot_password`, `reset_password`, and `verify_email_sent` modes.
   - Add "Forgot Password?" link and "Resend Verification Email" button with countdown/rate-limit notice.
   - Maintain botanical styling, accessibility, and error formatting.
3. Backend Security & Verification:
   - Ensure backend verifies valid JWT claims and prevents project access across different users.
   - Review `/api/auth/signup` and document production SMTP requirements.
4. Testing & Verification:
   - Run backend pytest and frontend build.
   - Verify unauthenticated and cross-user rejection.
