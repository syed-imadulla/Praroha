## 1. Context & Objectives

During hackathon demonstrations, the system must support:
1. `DEMO-01`: An instantaneous, deterministic full-universe seed (`The Sunken City: Bio-City`) that completely populates all 7 stages in < 500ms without relying on slow sequential API requests.
2. `DEMO-02`: Graceful, uncrashable error recovery if an external LLM fails, times out, or runs out of quota, falling back seamlessly to deterministic mock fixtures while attaching a user-facing warning.

---

## 2. Technical Tasks

### Task 1: Repository Method `create_canonical_demo_project()`
In `backend/app/repositories/project_repo.py`:
- Implement `create_canonical_demo_project(session: Session) -> ProjectRecord`:
  - Creates a `ProjectRecord(title="The Sunken City: Bio-City", seed_text="A child discovers a forgotten city beneath the ocean.", status="universe_unfolded", branch_name="main")`.
  - Inserts `SeedDNARecord` using `CANONICAL_SEED_DNA`.
  - Inserts 3 `WorldCandidateRecord`s using `CANONICAL_WORLDS`.
  - Inserts `WorldSelectionRecord` linking to Candidate 2 (`Bio-City`) with canonical rationale.
  - Inserts `WorldBibleRecord` with key locations, factions, history timeline, and canon facts from `CANONICAL_UNFOLD_WORLD_2`.
  - Inserts `CharacterRecord`s for Dr. Althea Thorne, Sentry Unit Nereus, Kaelen.
  - Inserts `CharacterRelationshipRecord`s.
  - Inserts `SceneRecord`s (Scenes 1, 2, 3).
  - Inserts baseline `EntityRevisionRecord`s for Dr. Althea Thorne and Scene 1.
  - Commits transaction and returns the created project.

### Task 2: Mount `POST /api/projects/canonical-demo`
- In `backend/app/routers/projects.py` (or `persistence.py` / `demo.py`):
  - Add endpoint `@router.post("/canonical-demo", response_model=APIResponse[ProjectRead])`.
  - Calls `project_repo.create_canonical_demo_project()`.
  - Returns `APIResponse(success=True, data=project.to_read_schema(), message="Canonical Bio-City universe populated successfully")`.

### Task 3: Resilient Fallback Wrapper in `gemini_provider.py`
In `backend/app/providers/gemini_provider.py`:
- Wrap `extract_seed_dna`, `generate_worlds`, and `unfold_universe` with `try / except Exception as exc`.
- In the `except` block:
  - Log error with logger.warning.
  - Fall back to `MockProvider().<method>(...)`.
  - Mark fallback triggered so upstream consumers know it gracefully degraded without failing.

### Task 4: Pytest Suite `backend/tests/test_demo.py`
- Test 1: `test_create_canonical_demo_project()` verifies that calling the repository method creates a project with all tables populated (DNA, 3 worlds, selection, bible, 3 characters, relationships, 3 scenes, revisions) in under 500ms.
- Test 2: `test_canonical_demo_endpoint()` calls `POST /api/projects/canonical-demo` via `TestClient` and verifies HTTP 200 with complete `ProjectRead`.
- Test 3: `test_gemini_provider_graceful_fallback()` simulates an API error / exception in Gemini provider and verifies it returns valid mock fixtures rather than raising unhandled exceptions.
