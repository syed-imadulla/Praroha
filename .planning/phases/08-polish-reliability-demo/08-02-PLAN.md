## 1. Context & Objectives

Wave 2 delivers the user-facing polish and evaluator presentation experience:
1. **Instant Full Universe (DEMO-01)**: 1-click button calling `POST /api/projects/canonical-demo` that instantly switches workspace state to the unfolded Bio-City universe with all 7 stages unlocked.
2. **Guided Demo Tour**: Floating spotlight cards walking judges through the 7-stage journey from Avyakta through the 6 Tattva transformations.
3. **Keyboard Shortcuts**: Effortless rapid navigation (`1-7` stage jumps, `i` inspector, `t` tour, `?` shortcuts cheat-sheet).
4. **Lineage DAG Zoom Controls**: Header buttons to zoom and fit large provenance graphs.
5. **Visual Polish**: Canonical demo seed highlight badge, Framer Motion spring hover animations.

## 2. Technical Tasks

### Task 1: API & Store Integration for Instant Demo
- In `frontend/src/api/client.ts`:
  - Add `createCanonicalDemoProject(): Promise<APIResponse<Project>>`.
- In `frontend/src/store/workspaceStore.ts`:
  - Add `loadCanonicalDemoUniverse(): Promise<boolean>`:
    - Calls `apiClient.createCanonicalDemoProject()`.
    - Calls `switchBranch(demoProject.id)` to load all relational entities.
    - Sets `unlockedStages: ['seed', 'understand', 'worlds', 'choose', 'unfold', 'trace', 'refine']`.
    - Sets `activeStage: 'unfold'`.
  - Add tour state: `tourOpen: boolean`, `tourStep: number`, `startTour()`, `nextTourStep()`, `prevTourStep()`, `closeTour()`.
  - Add shortcuts modal state: `shortcutsModalOpen: boolean`, `toggleShortcutsModal()`.
  - Add fallback warning toast: `providerFallbackWarning: string | null`, `setProviderFallbackWarning()`.

### Task 2: Create `GuidedTourOverlay.tsx`
- Floating spotlight cards for the 7-stage Guided Demo, representing the progression from Avyakta through the 6 Tattva transformations:
  - Step 1: Stage 1 (Seed) — *Avyakta (Starting Formless Potential)* — Raw creative premise.
  - Step 2: Stage 2 (Understand) — *Tattva 1: Bija (First Manifestation)* — Semantic Seed DNA distillation.
  - Step 3: Stage 3 (3 Worlds) — *Tattva 2: Srishti (Latent Forms)* — Exactly three contrasting creative archetypes.
  - Step 4: Stage 4 (Choose) — *Tattva 3: Sankalpa (Creative Commitment)* — The human-in-the-loop choice gate.
  - Step 5: Stage 5 (Unfold) — *Tattva 4: Vistara (Universe Expansion)* — Bible canon, characters, relationships, story beats.
  - Step 6: Stage 6 (Trace) — *Tattva 5: Sambandha (Causal Lineage)* — Provenance DAG back to root seed.
  - Step 7: Stage 7 (Refine) — *Tattva 6: Parinamana & Dharana (Transformation & Persistence)* — Versioning, branching, and state portability.
- Provides `Next Stage ->`, `<- Back`, and `Exit Tour` buttons.
- Automatically synchronizes `activeStage` to match the tour step as the user advances.

### Task 3: Create `KeyboardShortcutsModal.tsx`
- Dark glassmorphic modal displaying keycap badges:
  - `1` - `7`: Switch between Stage 1 (Seed) and Stage 7 (Refine)
  - `i`: Toggle Workspace Inspector drawer
  - `t`: Launch Guided Demo Tour
  - `?`: Toggle Keyboard Shortcuts Help
  - `Escape`: Close modals or tour overlay
- Pressing `?` or clicking the Help icon in the TopBar opens this modal.

### Task 4: Global Keyboard Listener in `WorkspaceCanvas.tsx`
- Bind `window.addEventListener('keydown', ...)`:
  - If target tag is `INPUT`, `TEXTAREA`, or `SELECT`, ignore.
  - `1`-`7`: call `setActiveStage` if unlocked.
  - `i` / `I`: `toggleInspector()`.
  - `t` / `T`: `startTour()`.
  - `?`: `toggleShortcutsModal()`.
  - `Escape`: close modal/tour.

### Task 5: Lineage DAG Zoom Controls in `TraceabilityCanvas.tsx`

- Wrap DAG canvas container in smooth transform style: `transform: scale(${zoomLevel})`, `transformOrigin: 'top left'`.
