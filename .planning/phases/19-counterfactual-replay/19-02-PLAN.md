# Phase 19: Plan 2 (19-02-PLAN.md) — Frontend Counterfactual Replay Canvas & Branching
**Status:** Completed ✅

## Wave 2: Frontend Counterfactual Replay UI (Codex Tab Integration, 50/50 Comparative Matrix, Divergence Delta Cards & Timeline Forking)

### Goal
Implement the frontend user experience for Counterfactual Replay (`CNTR-01`, `CNTR-02`), embedding a 5th navigation tab ("Counterfactual Replay" / `#codex-tab-replay`) and a top header launcher button ("What If I Chose Another World?" / `#launcher-counterfactual-replay-btn`) inside the Universe Codex. The interface renders a rejected candidate selector strip, a 50/50 side-by-side comparative matrix (Current Canon vs Alternative Candidate), 4 dedicated divergence delta cards (Protagonist, Tone & Atmosphere, Conflict & Stakes, Lore & Rules), exploration profile comparison meters, and an actionable timeline forking flow creating isolated child branches with parent immutability.

---

### Scope Boundaries & Non-Goals
- **Strictly in Scope**:
  - 5th Codex Tab `#codex-tab-replay` and Universe Header launcher button `#launcher-counterfactual-replay-btn`.
  - Rejected candidate selector strip with archetype badges and divergence indicators.
  - 50/50 side-by-side comparative layout contrasting canon universe with alternative candidate.
  - 4 visual divergence delta cards (Protagonist, Tone, Conflict, Lore) with divergence badges.
  - Exploration profile comparison meters displaying 4-metric deltas.
  - "Fork Timeline from This World" action button (`#fork-counterfactual-branch-btn`) with branch switching.
  - Workspace store actions and state synchronization.
  - Complete Playwright E2E test suite covering all 5 core user scenarios and capturing visual artifacts.
- **Strictly Out of Scope**:
  - Phase 20 Human-Only Zones.
  - Automatic full universe unfolding inside the comparison preview without branching.
  - Timeline merging or git-style cherry-picking.

#### 2. Implement Counterfactual Replay Canvas Component
- **File**: `frontend/src/components/CounterfactualReplayCanvas.tsx`
- **Responsibilities**:
  - **Candidate World Selector Strip**:
    - Horizontal card strip listing all rejected candidate worlds.
    - Badges for archetype, divergence archetype (`familiar`, `radical`, `inverse`), and title.
    - Clicking a candidate selects it and loads its delta comparison.
  - **50/50 Dual-Column Side-by-Side Comparative Matrix**:
    - **Left Column (Current Canon)**:
      - World title, concept logline, divergence archetype badge.
      - Active universe anchors: Lead protagonist character card, primary physical law from World Bible, main scene conflict.
      - Decision DNA Rationale badge: *"Why you chose this world"*.
    - **Right Column (Counterfactual Alternative)**:
      - Alternative world title, concept logline, divergence archetype badge.
      - Projected counterfactual anchors: Alternative protagonist conception, tone and mood contrast, alternative central conflict, lore & rule alterations.
      - Inferred exclusion pills: What was avoided by choosing current canon.
  - **4 Divergence Delta Cards**:
    - `Protagonist Divergence` (`User` icon): Lead character archetype, motivation, and arc comparison.
    - `Tone & Atmosphere Shift` (`Sparkles` icon): Emotional mood, sensory aesthetic, and visual palette contrast.
    - `Conflict & Stakes` (`Flame` / `Swords` icon): Primary friction, central crisis, and dramatic stakes.
    - `Lore & World Rules` (`BookOpen` / `Shield` icon): Physical laws, technological constraints, and societal rules.
    - Each card displays divergence intensity tag (`subtle`, `moderate`, `radical`, `inverse`).
  - **Exploration Profile Comparison Meters**:
    - Comparative visual delta bars for Seed Fidelity, Novelty, Conceptual Distance, and Feasibility.
  - **Branching Action Bar**:
    - Input for custom branch name (`data-testid="counterfactual-branch-name-input"`) with suggested auto-population (e.g. `counterfactual/sunken-time-capsule`).
    - Primary CTA: `"Fork Timeline from This World"` (`id="fork-counterfactual-branch-btn"`).
    - Loading feedback during branch creation and automated switch to child branch upon completion.
