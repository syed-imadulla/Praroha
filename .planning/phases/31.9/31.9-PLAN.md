# Phase 31.9: Error Handling, Demo Isolation & Product Truth Hardening — Plan

## Goal
Enforce absolute product truth across PRAROHA: eliminate all silent mock fallbacks in Real Mode, isolate Canonical Demo Mode completely, remove hardcoded/canonical lore and sample cards, fix the timeline and canon lore presentation bugs, make Export JSON actually download the project's Seed DNA, derive realistic project titles from seeds, ensure video generation is never faked, position stage buttons consistently at the bottom, and make error states clear with retry actions.

## Waves and Tasks

### Wave 1: Backend Truth Hardening & Bug Fixes
- **Task 1.1**: Eliminate silent mock fallbacks in Real Mode in `backend/app/providers/gemini_provider.py`.
  - When `not self.is_demo`: any Gemini failure must raise `AIProviderError` instead of falling back to `MockProvider`.
  - Preserve `MockProvider` strictly for explicit Demo Mode (`is_demo=True`).
- **Task 1.2**: Fix timeline parsing and schema resilience in `backend/app/models/unfold.py` and `backend/app/repositories/project_repo.py`.
  - Prevent string fragmentation (`Era Y Era e Era a...`).
  - Gracefully parse list of dicts, list of strings, or text into structured `TimelineEvent(era=..., event=...)`.
- **Task 1.3**: Implement automatic deterministic/AI project title derivation from seed in `backend/app/repositories/project_repo.py` and `backend/app/routers/projects.py`.
  - If title is generic ("Seed World Project" or empty), derive title from first sentence / key phrase of the seed text.
- **Task 1.4**: Video generation truth in `backend/app/services/media_service.py`.
  - Disallow fake video generation in Real Mode. Return clear error that video generation is in development.
